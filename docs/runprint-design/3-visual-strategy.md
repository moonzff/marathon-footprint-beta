## 一、设计原则(裁判 · 定稿)

### Runprint 设计原则 Design Principles

> 战略→视觉的承重桥。共 5 条。每条都能当裁判:任何视觉方案上桌,逐条打分,不合则砍。
> 上游可追溯链:Purpose / 三支柱(聚合·身份·可信)/ 人格(智者主+创造者次)/ 个性五词(可信·懂行·克制·讲究·有底气)/ Tone(懂行老跑友)/ 隐喻(印记·显影·聚合·生涯·段位·见证)/ slogan(你跑过的每一步,都算数)。

---

#### 原则一 ·「凭证感,不是仪表盘」(Credential, not Dashboard)

**含义**
视觉的第一观感要像一份**可信的身份凭证 / 证书 / 档案**,而不是一块实时跳动的运动仪表盘。信息要"被确证、被授予、被沉淀"的气质,而非"正在燃烧、正在冲刺"的气质。

**战略依据**
- 三支柱之"可信(验证)"+ 命门"自我表达(这就是我)"。
- 关键差异化:别人做"能量/速度/燃烧",Runprint 做"沉淀/凭证/段位/被看见"。
- 隐喻:印记 · 见证 · 段位。

**视觉含义**
- 形态:卡片/证书/档案页/印鉴 的稳定矩形与留白,优先于环形进度条、速度表盘、热力轨迹。
- 版式:对齐严谨、信息分级清楚,像证件而非像 feed 流。
- 质感:纸感、压印、烫印、骑缝、编号——"这份东西经得起核验"。
- 影像:成绩、奖牌、号码布以"被存档/被装裱"的方式呈现,不做动感模糊。

**取舍**
反对一切"实时性能可视化"的炫技(跳动数字、速度仪表、燃脂火焰)。牺牲"即时爽感",换"长期可信"。

---

#### 原则二 ·「克制即权威」(Restraint is Authority)

**含义**
靠"少"而不是"多"来建立专业感。一屏一个主角,大量留白,有限色彩,克制的字号跳跃。让人觉得"它不需要喊,因为它有底气"。

**战略依据**
- 人格主轴=智者;个性五词=克制 · 讲究 · 有底气。
- Tone:数据精确、判断笃定、不打鸡血、不替你尖叫。

**视觉含义**
- 色彩气质:低饱和、有限色板(1 主色 + 1 强调 + 中性灰阶);强调色只在"段位/确证"等关键时刻出现,不铺满。
- 字体:克制的字阶,理性无衬线为骨;允许一处"讲究"的衬线/类宋作为人格点睛,但不滥用。
- 动效:慢、少、有目的(显影、归档),拒绝弹跳/闪烁/庆典彩带。
- 版式:网格严谨,留白是主角不是边角料。

**取舍**
反对信息轰炸、撞色、满屏徽章、特效堆叠。牺牲"热闹/吸睛",换"高级/可信赖"。这条专治"什么都想塞进去"。

---

#### 原则三 ·「显影,而非点燃」(Develop, not Ignite)

**含义**
核心动态隐喻是**暗房显影 / 逐步聚合成形**——成绩与身份是"慢慢浮现、被沉淀下来"的,不是"被点燃、被引爆"的。运动感来自"成形"而非"加速"。

**战略依据**
- 核心隐喻(语言层已定):显影 · 聚合 · 沉淀 · 生涯。
- 关键差异化:沉淀 vs 燃烧。
- Purpose:让认真的跑者被"完整、可信地看见"——看见=显影。

**视觉含义**
- 动效语汇:渐显、聚合、归位、压印落定;时间曲线偏稳重(ease-out 收束),不要弹簧回弹。
- 影像/质感:从模糊到清晰、从散点到聚合、从空白到成形的过程感;颗粒/银盐/扫描线等"显影"质地可作候选。
- 色彩气质:深色背景上的"浮现"高于亮色背景上的"爆闪";由暗到亮的渐变服务于"显影"叙事。

**取舍**
反对火焰、爆发、粒子四射、速度线、霓虹拖尾。牺牲"瞬间冲击力",换"沉淀的厚度感"。

---

#### 原则四 ·「这是你的印,不是我们的奖」(Your Mark, not Our Medal)

**含义**
视觉服务于"跑者的自我表达",不是平台的自我表彰。重心是**这个跑者是谁**,而非"Runprint 这个品牌多厉害"。每个产出都应让跑者觉得"这说的就是我",且能体面地拿出去示人。

**战略依据**
- 价值主张命门=自我表达利益("这就是我,一个什么样的跑者")。
- 三支柱之"身份(显影)"。
- Tone:为你高兴但不替你尖叫;**不羞辱新人**——慢的、少的、刚起步的,也值得体面呈现。

**视觉含义**
- 版式:跑者的名字/印记/段位是绝对主角,品牌 logo 退居见证人位置(角标、骑缝、签发方),不抢戏。
- 影像:为"可分享、可示人"而设计——成为社交资产,而非平台内部报表。
- 个性化:同一套系统能体面承载"百马大神"与"首个 5K",视觉不靠成绩高低分贵贱。
- 形态:像"颁发给你的东西",署名是你,签发是它。

**取舍**
反对品牌凌驾用户、强 logo 露出、用成绩门槛制造视觉等级羞辱(把慢/少渲染成"弱")。牺牲部分"品牌曝光",换"用户认同与自豪"。

---

#### 原则五 ·「精确到可被核验」(Precise enough to be Verified)

**含义**
细节经得起放大检视——数据精确、对齐到位、单位/编号/日期一丝不苟。视觉的"讲究"体现在工程级的精密,而不是装饰的繁复。可信不是说出来的,是每个像素透出来的。

**战略依据**
- 三支柱之"可信(验证)"+ 聚合(收全)。
- 个性五词:可信 · 懂行 · 讲究。
- Tone:懂行老跑友——数据精确、判断笃定。

**视觉含义**
- 字体:数字优先选**等宽 / 表格数字(tabular figures)**,成绩、配速、距离对齐如账本/仪器刻度。
- 版式:基线网格、精密对齐、清晰的信息层级与单位标注;像招股书/检测报告那样可信。
- 质感:精密的细线、刻度、骑缝、编号、签发时间戳——"可核验"的视觉密码。
- 数据呈现:完整、准确、不夸大;留白处也透着"该有的都在,且都对得上"。

**取舍**
反对为美观牺牲准确、为装饰堆叠纹样、含糊的近似值。牺牲部分"自由发挥的视觉浪漫",换"工程级可信"。

#### 对"既有候选锚点"的裁决(公平复赛,不预设胜出)

> 01-foundation 的五个旧锚点回到候选池,用上面 5 条原则打分,赢家靠契合度晋级,并给出竞争对手。

- **现代宋 / 类宋衬线** —— 契合【二·讲究点睛】【一·凭证感】,但若全局滥用会违反【二·克制】。**裁决:候选保留,降为"人格点睛"而非"主力字体";主力应是理性无衬线 + tabular figures(原则五)。** 竞争对手:高品质中性无衬线(如 grotesque 类)担纲主力,衬线只点睛。
- **同心环纹** —— 形似"年轮/生涯沉淀",但环形极易被读成"进度环/仪表盘",踩【一】红线。**裁决:有条件候选——必须去"进度条化",做成"年轮/骑缝/声呐式显影",否则出局。** 竞争对手:**等高线/地形线**(更贴"段位海拔"且无仪表盘嫌疑)、**银盐显影颗粒**(贴原则三)。
- **桂冠** —— 强"奖"气质,直接撞【四·不是我们的奖】【三·非庆典】;且是跑步 App 通病(奖杯/奖牌)。**裁决:高风险,基本出局或仅作极弱化签发纹样。** 竞争对手:**印鉴/钢印/骑缝签发标记**(贴"凭证/签发"且不自夸)。
- **邮戳 / 骑缝** —— 强"签发·见证·可核验"气质,正中【一】【五】,且天然把品牌放在"签发方/见证人"位置正合【四】。**裁决:强候选,晋级。** 竞争对手:**检测报告编号体 / 防伪底纹**(同样贴"可核验",更冷静)。
- **档案绿** —— "档案/沉淀"叙事贴【一】【三】,但"绿"在跑步语境易滑向"健康/活力荧光",需严格限定为**低饱和墨绿/档案绿**并仅作有限主色。**裁决:候选保留但需色值体检(低饱和、偏暗、去荧光)。** 竞争对手:**暗房深(近黑墨蓝/石墨)+ 单一金属强调(铜/旧金,贴"印鉴/段位")**,可能比绿更贴"显影暗房 + 凭证印鉴"。

> 一句话结论:**邮戳/骑缝、印鉴、tabular figures、暗房深+金属强调**因高契合度领跑;**桂冠**因撞"奖"红线基本出局;**现代宋、同心环纹、档案绿**有条件晋级但需按原则改造与体检。最终拍板交由下一阶段(视觉疆域 / moodboard)在原则约束下竞稿。

## 二、关键词 → 视觉翻译矩阵

### Runprint 关键词 → 视觉翻译矩阵

> 上游：已签收战略书 + 语言识别手册。本矩阵把品牌抽象属性翻译成可执行的视觉语汇，作为设计字典。
> 推导链：战略/语言 → 设计原则 → 视觉语汇。下方每个翻译都标注了**它服务的战略命门**，可追溯、可反驳。

#### 一、先定设计原则（视觉的宪法，所有翻译向它对齐）

从人格"可信·懂行·克制·讲究·有底气"+ 隐喻"印记/显影/聚合/段位/见证"推导出 5 条原则：

| # | 设计原则 | 来源 | 反面（要避开的） |
|---|---------|------|----------------|
| P1 | **凭证感 > 装饰感** | 可信/验证支柱 | 花哨、营销味、贴纸感 |
| P2 | **留白即克制，密度即懂行** | 克制人格 + 数据精确 | 信息轰炸、满屏渐变 |
| P3 | **沉淀的时间质感，非爆发的瞬间** | 沉淀/生涯隐喻 | 速度线、动感模糊、燃烧 |
| P4 | **印记可被"显影"，不靠喊** | 显影/印记隐喻 | 高饱和呐喊、奖杯特效 |
| P5 | **段位是事实的呈现，不是炫耀** | 身份/段位，中立立场 | 排行榜羞辱、等级特效光 |

---

#### 二、关键词 × 视觉维度 主矩阵

> 维度：形态语言 / 色彩气质 / 字体气质 / 质感肌理 / 版式网格 / 动效倾向 / 影像图形手法
> 关键词「不羁」的判断见第四节（结论：降级，不进主盘）。

##### 1. 可信 / 凭证

| 维度 | 视觉翻译 |
|------|---------|
| 形态语言 | 直角/微圆角矩形卡片、清晰边框、骑缝线、可被"签发"的票证结构；闭合形优于开放形 |
| 色彩气质 | 冷中性为骨（墨蓝/石墨/纸白），低饱和、中低明度；权威感来自克制而非鲜艳 |
| 字体气质 | 等宽字体承载编号/校验码；无衬线正文交代事实；字重对比小，不喊 |
| 质感肌理 | 纸纹、纤维、防伪底纹（极淡）、压印/凹凸感；忌塑料高光 |
| 版式网格 | 严格基线网格、字段对齐如表单/证书；信息分区清晰 |
| 动效倾向 | "盖章/签发"的确定性微动效（落定、定格），无弹跳无缓动夸张 |
| 影像图形 | 编号、二维码/校验码意象、骑缝章、签发线；可验证细节是主角 |

##### 2. 懂行 / 精确

| 维度 | 视觉翻译 |
|------|---------|
| 形态语言 | 刻度、坐标、网格点、配速曲线；几何精确，线条有"测量"感 |
| 色彩气质 | 单色+1 功能强调色（数据高亮）；强调色冷静（青/钴），不暖不躁 |
| 字体气质 | 等宽/表格数字（tabular figures）、上下标、单位排版讲究；小字号也清晰 |
| 质感肌理 | 哑光、精密仪表盘质感、细网格底；干净无噪点 |
| 版式网格 | 高密度但有呼吸的数据版式；模块化，像专业仪表/年鉴 |
| 动效倾向 | 数据"逐项校准/对齐"式动效，理性、可预期；数字滚动收敛到定值 |
| 影像图形 | 配速/海拔/心率曲线作为图形语言、刻度尺、等高线 |

##### 3. 克制 / 留白

| 维度 | 视觉翻译 |
|------|---------|
| 形态语言 | 少即是多，大面积空场；单一主体居中或定位精确 |
| 色彩气质 | 大量纸白/灰场，强调色占比 <10%；明度高、饱和低 |
| 字体气质 | 一个字族走天下（家族内做层级），克制字重与字号跳变 |
| 质感肌理 | 几乎无肌理或极淡纸感；负空间本身是设计元素 |
| 版式网格 | 宽边距、强对齐、少分割线；用空间分组而非框线 |
| 动效倾向 | 极简、慢、少；进出柔和，绝不抢戏 |
| 影像图形 | 图形少而精，一图一意；拒绝装饰性图元 |

##### 4. 沉淀 / 档案

| 维度 | 视觉翻译 |
|------|---------|
| 形态语言 | 档案卡、索引标签、卷宗/层叠结构、时间轴；可堆叠归档的模块 |
| 色彩气质 | 微暖中性（纸黄/灰褐微调），低饱和、做旧但不脏；岁月感而非陈旧感 |
| 字体气质 | 略带文献感的衬线/现代宋承载标题；正文回到中性无衬线 |
| 质感肌理 | 纸张、卡纸、装订线、轻微氧化/年代肌理；克制使用 |
| 版式网格 | 年鉴/卷宗版式、编目式、时间纵轴；条目化、可索引 |
| 动效倾向 | "翻页/调阅档案/抽屉拉出"式动效，从容、有重量 |
| 影像图形 | 时间戳、归档编号、索引页、生涯纵览图谱 |

##### 5. 显影 / 印记

| 维度 | 视觉翻译 |
|------|---------|
| 形态语言 | 从无到有的"成像"、印章/钢印/水印形态、轮廓逐渐清晰 |
| 色彩气质 | 暗场显影（深底上浮现）或纸上印记（浅底压色）；单色显影优先 |
| 字体气质 | 字可被"印上去"——压印、烫印、镂空感；标题字有物质重量 |
| 质感肌理 | 显影/感光、油墨吃进纸、压痕、钢印凹凸；这是 Runprint 的招牌肌理 |
| 版式网格 | 主印记居核心位、留白衬托；印记是"被授予"的，居中而庄重 |
| 动效倾向 | **显影动效是品牌签名**：暗房成像、墨迹渗开、印章落定、轮廓由虚到实 |
| 影像图形 | 印章、钢印、水印、感光成像、指纹/足印意象（克制处理） |

##### 6. 聚合 / 收全

| 维度 | 视觉翻译 |
|------|---------|
| 形态语言 | 散点收拢为一、碎片归整为整体、模块拼合成全景；网格收纳 |
| 色彩气质 | 中性底 + 来源多色被"收编"为统一色调；杂色归一 |
| 字体气质 | 统一字族把异源数据"说成一种语言"；标签体系一致 |

#### 四、关键词「不羁」的判断

**结论：不进主盘，降级为边缘调味。**

理由（可追溯）：
- 与人格"克制·讲究·有底气"**直接冲突**。智者人格的"有底气"是笃定，不是叛逆。
- "不羁"是燃烧/街头/潮牌跑步品牌的领地，正是 Runprint 要区隔的对象。
- 价值命门是"被完整可信地看见"（被授予的凭证），不是"我行我素的张扬"。

保留的微量用法：自我表达环节里"留一处可个人化的强调点"，允许一丝个性，但**锁在体系内**，不破坏中立与克制。

#### 五、跑步 App 通病清单 — Runprint 必须避开的视觉手法

| 通病手法 | 为何是病 | 违背的原则 |
|---------|---------|-----------|
| 荧光/霓虹高饱和色（荧光绿/橙/电光蓝） | 能量呐喊，喊而非证 | P1 凭证感、P2 克制 |
| 速度线 / 动感模糊 / 倾斜冲刺 | 表达"瞬间爆发"，与沉淀相悖 | P3 沉淀时间质感 |
| 燃烧/火焰/热力图燃感 | "卡路里燃烧"叙事，能量系 | P3、人格克制 |
| 奖杯/奖牌特效、闪光粒子、彩带礼花 | 炫耀式荣誉，撞中立 | P5 段位是事实非炫耀 |
| 等级升级闪光秀、霓虹进度条 | 游戏化打鸡血 | P4 不靠喊、P5 |
| 排行榜红绿羞辱、超越箭头 | 替你尖叫/羞辱新人，违 Tone | 人格 Tone |
| 大幅运动摄影+励志大字+渐变叠加 | 鸡汤海报范式，营销味 | P1、P2 |
| 弹跳/果冻/夸张缓动动效 | 活泼可爱，非笃定庄重 | 智者人格 |
| 彩虹色等级分级（铜银金钻彩） | 廉价游戏分级，损凭证感 | 用材质/形替代 |
| 圆形进度环当核心视觉（撞 Apple/Nike） | 已被占满，且偏"运动量"叙事 | 中立 + 差异化 |

**一句话收敛**：Runprint 的视觉是**"出版社/档案馆/签发机构"的气质，不是"运动品牌/健身房"的气质**——它显影、签发、归档、见证，而不喊、不烧、不炫。

需要的话，下一步可把"视觉疆域"七条做成 3 个可视的方向板（Direction A/B/C）供选型 A/B 测试。

## 三、三条视觉 Territory(比稿)

### 视觉疆域候选 A · 田野档案 Field Archive

> 客观评估稿。此前是 01-foundation 的"预设胜出"方向,现已按方法论降级为"待推导的候选之一"。本文给它公平的竞争对手,并诚实标注它哪里站得住、哪里会输。所有视觉论证均回指战略书 / 语言手册 / 设计原则,不引用任何被降级的预设结论作为依据。

---

#### 0. 先校准:它要回应的"设计原则"是哪几条

从战略书 + 语言手册蒸馏出的可执法设计原则(视觉必须服务这些,而非反过来):

- **P1 反通病**:与所有跑步 App(荧光/速度/燃烧/奖杯)彻底区隔——区隔来自定位差异(沉淀 vs 能量)。【战略 B1、blueprint§87 第一性原则】
- **P2 可信优先于好看**:视觉先传"可被信任/经得起查",好看是真实应得的回报。【价值观 2、支柱三可信】
- **P3 智者克制**:话留三分、让位给数据;不抢戏、不刷存在感;禁浮夸。【人格、Voice Chart 7、tone 克制=4】
- **P4 显影命门**:视觉要表达"这就是我,一个什么样的跑者"——自我表达利益是命门,需被放大。【C3 命门、语言收口】
- **P5 中立见证**:不是主办方站台,是中立第三方盖章;视觉要有"裁判/官方记录"的可信感而非赛事方的热闹。【RTB、Voice Chart 3】
- **P6 完整聚合**:把散落长尾(线下/海外/越野/小赛)平等收纳、一处看全的"整全感"。【支柱一、价值观 3】
- **P7 等级渐进披露·不羞辱**:荣誉显影给想要的人,绝不把"未评级"糊在所有人脸上。【兼容性铁律】

---

#### 1. 一句话概念

> **「你的完赛,被一座中立档案馆永久收讫、盖章存档——一份经得起查、值得你署名的跑者生涯卷宗。」**

视觉把产品显影成 **一座中立、严谨、有年代纵深的"完赛档案馆"**:每一场比赛是一份被收讫、编号、验真、归档的凭证;整段生涯是一卷可署名、可示人的卷宗。

**它如何回应设计原则:**
- 直接命中 **P2 可信**(档案=凭证=经得起查)、**P5 中立见证**(档案馆是中立第三方,不是赛事方)、**P6 完整聚合**(档案馆的天职就是"收全、不漏、归档")。
- 借"卷宗署名"承接 **P4 显影命门**(这份卷宗就是"我是谁")。
- "档案"的安静、严谨气质天然贴 **P3 克制**。
- 它对 **P1 反通病** 的回应**最锋利**:能量系做"此刻燃烧",档案系做"永久存档"——这是语义上最远的对立面,区隔最干净。

**诚实标注**:这是该候选**最强的支点**——可信/中立/完整三条护城河里,有两条(可信、聚合)是档案隐喻的母语。下面的风险段会说明它在 P4(命门)上是相对弱项,这正是要靠竞争对手检验的地方。

---

#### 2. Mood / 关键词

> **沉淀 · 收讫 · 凭证 · 纵深 · 严谨 · 体面 · 永久**

辅助氛围词(择用):笃定、馆藏、署名、经手、年轮。

明确**排除**的氛围词(防止滑向通病或跑偏人格):热血、冲刺、燃、爆发、潮酷、赛博、轻盈可爱。

#### 3. 色彩方向

**气质定调:不是"自然/户外绿",是"档案馆/装订布/牛皮纸/钤印朱"的人造收藏色。** 关键区别——能量系的颜色是**发光的**(荧光绿、电蓝在屏幕上"亮起来"),档案系的颜色应当是**反光的、有重量的、像油墨印在纸上**的。这一点是它服务"沉淀+凭证"而非"能量"的色彩第一性原理。

| 角色 | 气质描述 | 示意 hex 区间 | 为何服务"沉淀/凭证"而非"能量" |
|---|---|---|---|
| 底色 · 深档案绿 | 深到接近墨黑的装订布绿/图书馆布面绿,**低明度、低彩度** | `#16201A`–`#1E3A2A` | 低饱和=不发光=非能量;深沉=馆藏纵深感。与 Strava 荧光绿 `#FC4C02`/电蓝隔开整整一个色彩象限。 |
| 纸面 · 温暖奶白 / 档案米 | 牛皮档案卡、未漂白纸的暖白,微偏黄,**有纸的温度不刺眼** | `#F6EEDD`–`#FBF6E9` | 纸=凭证载体;暖白传"被妥善保存"的体面,而非数据屏的冷白。 |
| 凭证印 · 钤印朱 / 克制陶土 | 公文骑缝章的暗朱砂 / 收讫戳的陶土红,**哑光不鲜艳** | `#B5462E`–`#C65A3A` | 这是"盖章/收讫/验讫"的语义色,代表**可信验证**(P2);哑光使它像盖在纸上的油墨,不像 CTA 的警示橙。唯一行动色可由它收敛而来。 |
| 荣誉 · 完赛金(冷处理) | **古铜/旧鎏金**而非闪亮金,等级徽章/PB 专属,**严格渐进披露** | `#B68A3E`–`#D4A85A` | 金=完赛荣誉峰值(P4),但必须"旧金/铜"质感——闪亮金会滑向奖杯通病(P1);旧金="被时间认证过的荣誉"。**默认折叠,只给想要的人(P7)**。 |
| 验真 · 墨黑 / 钢灰 | 成绩数字、编号、骑缝线用的近黑墨色与中性灰 | `#0E1310` / `#5B6660` | 数字用墨黑=印刷凭证的严肃;让数据"自己说话"(P3),不靠彩色卖情绪。 |

**整体配色逻辑(各司一职,杜绝"全是绿")**:深绿是**馆**(底/纵深)· 奶白是**纸**(凭证载体)· 朱土是**章**(可信收讫)· 旧金是**荣誉**(峰值,渐进披露)· 墨黑是**数**(经得起查)。

> **关键风控**:这套色板与被降级的 01-foundation 旧色板**有意拉开**——旧板用了苔绿 `#8BC34A`/亮金 `#F7BD72`/橙陶 CTA,偏"明亮、有能量感"。本候选刻意**压暗、去饱和、把金做旧、把红从橙 CTA 改成钤印朱**,正是为了让它真正落在"沉淀"而非"明快",避免旧方向"嘴上说沉淀、用色却偏活泼"的自我矛盾。

#### 4. 字体方向

> 气质:**碑刻证书的庄重 + 瑞士理性的中立 + 成绩册的精确**——三者分管"荣誉感 / 可信感 / 数据感"。

| 角色 | 方向 | 气质与依据 |
|---|---|---|
| 中文标题 | **带骨力的现代宋**(思源宋 Heavy / 寒蝉端宋一类) | 宋体横细竖粗、有"碑刻/证书/署名"的庄重感,服务 P4 荣誉显影与 P5 中立权威。比黑体更"有年代、有凭证感",区隔能量系清一色的粗黑体。 |
| 中文正文 | 思源黑 / PingFang，中等字重 | 正文要"说人话"的清楚(对应语言手册老跑友口吻),不与标题抢戏(P3)。 |
| 英文标题 | **瑞士理性无衬线**(Neue Haas Grotesk / Söhne) | 中立、克制、不情绪化,正是智者人格;避开圆体(可爱)与压缩体(运动潮)。 |
| 成绩数字 ★命门 | **等宽 tabular figures**(Söhne Mono / IBM Plex Mono) | 成绩/配速/编号永远等宽对齐——这是"成绩册/凭证"气质的字体命门,也让"经得起查"被肉眼感知。**这是全方案里最不可妥协的一条**,任何候选方向都应继承。 |

中英搭配气质:**现代宋(庄重)压标题、瑞士无衬线(中立)做骨架、等宽数字(精确)立可信**。三套字各自对应人格里的"讲究 / 克制 / 有底气"。

#### 5. 形态 / 图形语言

母题倾向(按"与档案隐喻的契合度 + 与战略的可追溯性"排序):

1. **收讫戳 / 验讫章(最核心)**:每场完赛盖一枚"城市+年份+距离"的收讫戳。语义=可信验证(P2)+ 中立第三方经手(P5)。**绕开"护照"二字**(田协已占,战略红线),用"档案馆收讫"拿到盖戳收集的仪式感而不撞红线。
2. **骑缝线 / 编号 / 归档卡**:卷宗骑缝章、档案编号、卡片化的"一场一卡"。传"经手、可追溯、防篡改"——把"经得起查"做成可见的形式语言。
3. **等高线 / 同心环**:作为"指纹(唯一身份)= 折返圈 = 完赛圈数 = 城市等高线"的四义同形母题,可承接 logo。**但需诚实标注**:同心环是该候选与"地形测绘/制图"气质的共用资产,不是档案馆独有,使用时要靠盖章/纸张/编号把它"拉回档案语境",否则会漂向"户外地图"那一类竞品方向。
4. **桂冠 / 等级环(谨慎)**:作为段位徽章的承载。**风险点**——桂冠极易滑向"奖杯/冠军"通病(P1 雷区)和"过于复古/纹章"的沉重(见风险段)。建议**降权使用**:用"旧金细线桂冠半环"而非实心浮雕桂冠,且严格渐进披露(P7)。

> 形态总原则:**让"纸 + 章 + 编号"主导,让"环 + 冠"辅助。** 前者是档案语境的独占资产,后者是易被通病和复古吞掉的高风险资产。

---

#### 6. 影像 / 质感

- **纸张质感**:档案卡、牛皮纸、未漂白纸纹——是"凭证载体"的物理隐喻(P2)。克制使用,避免做成做旧滤镜堆砌(否则滑向复古)。
- **钤印 / 油墨**:盖章的不均匀油墨边缘、骑缝章的压痕——传"被经手、被验讫"。
- **冷烫金 / 压凹(deboss)**:荣誉徽章用旧金冷烫或压凹,而非鲜亮浮雕——"被时间认证的荣誉"质感,严格用于峰值与等级(P4 + P7)。
- **档案卡版式**:一场一卡、可归档、可署名,呼应"卷宗"。
- **明确排除**:发光描边、霓虹辉光、速度残影、粒子/火焰——这些是能量系的质感语言(P1 雷区)。

---

#### 7. 版式气质

- **像一份被妥善归档的卷宗,不像一张运动海报**:留白多、信息分层、等宽数字成列、骑缝线/编号点缀。
- **数据成列、让数据自己说话**(P3):成绩用等宽数字右对齐成表,而非大字号煽情。
- **盖章式焦点**:收讫戳/认证戳作为右下角的"防伪/荣誉印记",从"广告水印"升级为"用户不舍得裁掉的荣誉印"——这是把分享病毒性建立在荣誉感而非促销上(贴 P4 + 反促销话术)。
- **庄重而不沉闷**:靠暖白纸面 + 充足留白 + 现代宋的骨力,避免深绿+复古导致的压抑(见风险)。

---

#### 8. 适用场景

**强场景(它的主场):**
- **公开主页 / 生涯卷宗**:档案纵深、收讫归档的气质在"一整段生涯"上最成立——这是产品身份层的脸面。
- **可信 / 验证相关界面**:去重、交叉验证、官方背书核对——档案语言是这里的母语(P2)。
- **完赛海报右下角认证戳 / 收讫戳**:荣誉印记,贴情绪峰值且不舍得裁。
- **About / 品牌故事 / B 端(赛事方·赞助商)**:中立、严谨、可核验的气质对 B 端信任建立极有利(受众变体③④)。
- **年度纪念册 / 实物打印**:纸张/钤印/卷宗气质与实物 SKU 天然咬合(blueprint 增长期变现)。

**偏弱场景(它的短板,要诚实):**
- **完赛峰值的"替你高兴"瞬间**:档案的冷静严谨,在需要一点点温度的庆祝场景(tone 允许峰值升温到 3)会显得**太冷、太肃**。需要旧金/朱土来"升温",但仍可能不如更暖的候选方向有感染力。
- **拉新破圈的小红书首图**:档案气质"高级但低刺激",在信息流里的**第一眼抓眼球**可能弱于更有视觉张力的方向——而小红书爆款是冷启动命脉(blueprint§GTM)。这是该候选最实际的商业风险。
- **入门 / 首马跑者**:卷宗/段位/钤印的"严肃凭证感",对新人可能略有距离(虽 P7 渐进披露能缓解)。

---

#### 9. 风险与规避

| 风险 | 会怎样失败 | 规避手段 |
|---|---|---|
| **过于复古 / 怀旧**(最大风险) | 牛皮纸+做旧+桂冠+宋体叠加 → 像民国档案馆/老字号,与"认真做、可盈利的现代产品"气质冲突 | 用**瑞士无衬线 + 等宽数字**做现代骨架,纸张/钤印只做点缀而非铺满;桂冠降权为细线半环;做旧只用于荣誉徽章,不用于整体 UI。**现代理性是底,档案气质是味,比例约 7:3。** |
| **过于沉重 / 压抑** | 深绿底+严肃宋体+肃穆留白 → 像政务/法律文书,撞官方《护照》的"政务感"(战略要主动绕开的近邻) | 靠暖白纸面提亮、旧金点睛、版式呼吸感破沉闷;严禁满屏深绿。**关键:别让它像"被签发的政务文件",要像"你自己署名的私人卷宗"**——主权感(归跑者本人)是与政务感的分水岭。 |
| **命门 P4 偏弱** | 档案隐喻擅长"可信/收纳",但"这就是我"的**自我表达张力**相对内敛,可能不够"想晒" | 把"署名卷宗"做足——卷宗封面是用户的脸/名/段位,强调**主权与署名**而非冷藏归档;让旧金荣誉与个性化(城市版图/装备/风格)承担表达欲。**这是它最该被竞争对手挑战的地方。** |
| **第一眼刺激不足** | 高级=低刺激,信息流抓眼球弱,伤拉新 | 海报版可允许"一枚醒目收讫戳/一道旧金"作视觉锚点提刺激;但这是**带着镣铐跳舞**,若拉新权重压倒一切,应让位给更有张力的候选。 |
| **"自我矛盾"复发** | 旧 01-foundation 嘴上"沉淀"、用色却偏明快活泼 | 本候选已主动压暗去饱和、把金做旧、把橙 CTA 改钤印朱(见 §3 风控)——执行时须守住,否则又变回"伪沉淀"。 |

---

#### 评估收口(客观裁断)

**它赢在哪**:对三条护城河里的"**可信(P2)**"和"**完整聚合(P6)**"以及"**中立见证(P5)**",田野档案是**母语级契合**——没有哪个隐喻比"中立档案馆收讫存档"更直给地表达"经得起查、收全、不办赛的第三方"。它对 P1 反通病的区隔也最锋利(存档 vs 燃烧是语义最远的对立)。

**它输在哪 / 待竞争对手检验的**:① **命门 P4(自我表达"想晒")相对内敛**——这是身份产品的核心价值,档案的冷静可能压抑表达欲;② **拉新第一眼刺激偏弱**,而小红书爆款是冷启动命脉;③ **复古/沉重的下行风险真实存在**,需要靠"现代理性 7 : 档案味 3"的纪律性配比来压住,执行容错率低。

**一句话**:它不该因为是旧方向被偏袒,也不该因被降级就被低估——它是"可信/中立/聚合"三件套的**最强候选**,但在"显影命门(想晒)"和"拉新刺激"两条线上,必须放一个更暖、更有表达张力的对手(如偏向"显影/暗房冲洗"或"个人主权署名"气质的方向)与它正面比稿,才能确认它是靠契合"赢得",而非靠惯性"预设"。

### 视觉疆域 B：制式凭证 The Record / Ledger

> Runprint 阶段3 · 与"田野档案"对垒的另一极。一句话先行，后面逐条交付。

---

#### 一句话概念

**「一份关于你的官方成绩册——不抒情，只记录；正因为什么都没多说，所以每一个数字都作数。」**

把 Runprint 做成一份权威机构会签发的**制式文件**：成绩册、登记簿、认证书、账本。它不"展示"你跑得多酷，它"记载"你跑过的事实。可信不靠说服，靠形式本身就是凭证的样子。

---

#### 如何回应设计原则

| 战略锚点 | 制式凭证的回应方式 |
|---|---|
| **可信（命门支柱·验证层）** | 视觉直接挪用"官方记录"的形式编码：编号、签发、表格、印章位。可信不是装饰出来的，是**格式**自带的——人对"制式文件"的信任是肌肉记忆。 |
| **克制（人格核心词）** | 近黑白、零渐变、零光效、几乎零图标。留白即克制，删到不能再删，让数据独自站立。 |
| **懂行（人格核心词）** | 排版即专业。等宽数字精确对齐、表头层级森严、计量单位规范——内行一眼看出"这人讲究"。 |
| **讲究 / 有底气** | 网格的极致严谨本身就是底气。不喧哗，但每条线都在该在的位置，挑不出错。 |
| **自我表达（价值命门）** | 表达方式是**"我的记录经得起核验"**——不是情绪宣泄，是"这是我的生涯，逐项在册"。一种克制的骄傲。 |
| **与跑步 App 区隔** | 别人是仪表盘（荧光/速度/燃烧），这里是**文献**。彻底跳出"运动科技"视觉，进入"档案/法律/金融凭证"视觉。 |

---

#### Mood / 关键词

`登记在册` · `经得起核验` · `逐项记载` · `官方签发` · `白纸黑字` · `精确对齐` · `权威留白` · `不容辩驳`

参照物：纸质护照内页 · 央行钞票编号 · 学位证书 · 体检报告单 · 老式航海日志 · 证券交割单 · 博物馆藏品标签 · 马拉松官方完赛证书（PDF 那一版，不是奖牌）。

---

#### 色彩方向

**定调：近黑白单色系。彩色是这里的禁忌。**

| 角色 | 取值区间 | 说明 |
|---|---|---|
| 墨黑（主文字/线） | `#1A1A1A – #111111` | 不用纯 `#000`——纯黑在纸感语境里太"屏幕"，墨黑更像油墨印刷。 |
| 纸白（底） | `#FAF8F3 – #F4F1EA` | 偏暖的纸白，象牙/档案纸调，不用刺眼的纯 `#FFF`。带一点"陈放感"。 |
| 灰阶（分隔/次级信息/表格线） | `#8C8C8C / #C9C5BC / #E5E1D8` | 三档灰承担全部层级，不靠颜色靠明度。 |
| **唯一强调色（克制使用）** | 朱红印泥 `#B23A2E – #9E2B20` | 仅用于"认证/签发"语义点：印章、骑缝、验真标记、关键编号。**全屏占比 < 2%**。 |

**为什么"近黑白"最大化可信与克制：**
1. **彩色 = 营销，黑白 = 记录。** 所有跑步 App 用颜色调动情绪（红=心率燃烧、绿=配速达标）。Runprint 拒绝调动情绪，只陈述事实——黑白是"我不需要说服你"的姿态。
2. **黑白把全部注意力逼回数据本身。** 没有颜色抢戏，5:24 的配速、Sub-3 的成绩就是唯一的主角。
3. **朱红的克制是关键。** 唯一的彩色给"验真/签发"——它一出现就有分量，因为通篇就这一点红，正如真公文上的那一枚章。彩色越省，越像真凭证。

替代强调色（若朱红太"中式公章"）：档案靛蓝 `#1F3A5F`（接近护照/法律文书的钢印蓝）。二选一，绝不并用。

---

#### 字体方向

**强排版驱动。三个声部，等宽数字是绝对主角。**

| 角色 | 方向 | 备选 |
|---|---|---|
| **成绩数字（主角）** | **等宽（Monospace）数字**——成绩、配速、距离、编号、日期全部等宽，确保竖排完美对齐，天然带"账本/终端/交割单"气质 | Söhne Mono / IBM Plex Mono / Roboto Mono；中文环境数字用等宽，避免比例字体 |
| **标题 / 权威声部** | 二选一定调（这是疆域内最大的分叉）：**A. 权威衬线**（学位证/法律文书感，更"文献/典籍"）= Noto Serif / 思源宋；**B. 瑞士无衬线**（瑞士国际主义/招标书/瑞士护照感，更"现代官方/中立机构"）= Helvetica Now / Inter / 思源黑 | 建议偏 **B 瑞士无衬线**——它比衬线更"中立机构"、更去情绪、更贴"智者克制"且不显老气；衬线易滑向"怀旧奖状"，与田野档案的复古撞车 |
| **标签 / 元信息** | 小字号、字间距拉开（letter-spacing）、全大写或小型大写的字段标签（`DISTANCE` `PACE` `FINISH TIME` `CERT. NO.`）——表单字段那种 | 同标题字族的轻量字重 |

**铁律：** 数字永远比标签显眼。标签是引导，数字是内容。一张图里，最大的元素一定是某个成绩数字。

---

#### 形态 / 图形语言

**全部来自"制式文件"的零件库，没有一件是装饰。**

- **表格 / 栏线**：横纵分隔线、表头底纹、斑马纹行——生涯成绩逐项列表的天然容器。
- **标尺 / 刻度**：边缘刻度、距离标尺、里程碑刻度线——计量感，呼应"精确"。
- **分隔线层级**：粗实线（章节）/ 细实线（行）/ 点线（折叠/骑缝）——靠线宽建立秩序，不靠色块。
- **印章 / 验真位**：朱红圆形/方形印章，置于"签发"语义点；可做骑缝章压在边缘——**唯一允许的"图形情绪"出口**。
- **编号 / 流水号**：`CERT. NO. RP-2026-004217` 这类签发编号、流水号、校验位——可信的微观证据。
- **网格 / 基线网格**：所有元素吸附严格网格，包括隐形基线网格让文字行行对齐。
- **字段框 / 表单位**：`姓名 ___ 项目 ___ 成绩 ___` 的填写式版面，像登记表/报名表/交割单。
- **留白本身是零件**：大面积权威留白 = "这份文件不屑于填满"，是底气。

**明确排除：** 桂冠、奖杯、奖牌、火焰、闪电、速度线、荧光高光、渐变、拟物纹理、emoji。

---

#### 版式气质

- **信息密度：高，但分区极清晰。** 像财报/成绩单——单位面积信息量大，但靠网格与分隔线切得清清楚楚，不拥挤。
- **对齐：偏执级。** 数字右对齐或小数点对齐，标签左对齐，列与列严格成栏。一个像素的错位都破坏可信。
- **网格：极致克制的栏格系统。** 强烈建议**单色 + 严格栏格 + 大留白**三件套；版心收紧，四周留权威白边（像证书的边距）。
- **层级靠"位置 + 字号 + 字重 + 明度"**，不靠颜色、不靠装饰。
- **节奏：静。** 没有动势，没有引导视线的箭头。读者像在读一份文件，从上到下，逐项核对。

---

#### 适用场景

**强场景（这套打法的主场）：**

- **生涯成绩册 / 完赛列表**：逐项罗列历史比赛——表格语言天生为此而生，是最强落点。
- **官方完赛凭证 / 认证卡**：单场比赛的"签发证书"，编号 + 印章 + 成绩，可分享、可验真，直击"可信"支柱。
- **段位 / 等级认定页**：把"段位"做成资格认定书的样子，权威感拉满。
- **数据详情 / 核验页**：聚合后的数据明细、来源核验——"经得起核验"的字面落地。
- **PDF / 可打印导出**：天生适合打印，因为它本来就长得像正式文件。

**偏弱场景（需要谨慎或混搭补强）：**

- **社交分享卡（朋友圈/IG）**：纯黑白在彩色信息流里可能"太素、不抓眼"——需靠一枚朱红印章 + 一个巨大成绩数字制造记忆点，否则容易被划走。
- **新人首跑 / 情感时刻**：第一次完赛的激动，纯账本语言可能偏冷——需要文案补温度（见风险）。
- **运营活动 / 促销**：制式凭证不擅长喊"限时优惠"，强行用会精神分裂。

---

#### 风险与"补一点人味"

**核心风险：过于冷峻、没有温度、压抑自我表达的情绪。** 一份账本可能让人"敬而远之"而非"想晒出去"；新人完赛的喜悦被一张体检单式的页面浇灭。

**补救（在不破坏"克制凭证"内核的前提下）：**

1. **温度来自文案，不来自视觉。** 视觉保持冷静，让 Tone（懂行老跑友）在文字里给温度：一句克制的判语 ——「Sub-3，已入册。这个成绩，5% 的跑者做得到。」——比任何荧光特效都动人。**冷视觉 + 暖判语**是这套的灵魂配方。
2. **印章是情绪出口。** 那一枚朱红印章/验真标记，是整份冷文件里唯一的"心跳"。它落下的瞬间＝"被官方承认了"——把全部情绪压强集中到这一个点，反而比满屏特效更有仪式感。
3. **"签发给：你的名字"。** 把用户名字放在证书的签发对象位（`签发予 ___`），制式语言一旦指向"你"，冷文件立刻变成"我的文件"——自我表达由此成立，且比炫酷头像更有分量。
4. **关键成绩数字可破格放大。** 允许某一个成绩数字打破网格、超大号呈现——冷静通篇里一处"放声"，给情绪一个合法的高潮，又不靠颜色。
5. **微仪式动效（数字场景）：** 盖章动效、数字逐位翻动（机械式翻牌）、编号生成——克制的机械感动效，既守住"制式"调性，又给一点"正在签发给你"的郑重时刻。

---

#### 与"田野档案"的对位（一句话）

田野档案靠**质感与时间**讲可信（手作、复古、有包浆的温度）；制式凭证靠**形式与精确**讲可信（官方、当下、零情绪的权威）。前者像一本你私人的跑步手账，后者像一张机构签发给你的完赛证书——**一个让你"摩挲珍藏"，一个让你"郑重出示"。** 这是给田野档案最硬的对手。

### 视觉疆域 C 充分发展稿 ·【显影 Develop / Darkroom】

> 上游可追溯锚点（每条视觉决定都挂在这几句上）:
> - Purpose:「让每一个认真的跑者,都被**完整、可信地看见**」——"被看见"是 Purpose 的终点动词。
> - 语言层已钦定隐喻(2-verbal §支柱二):「**零散的完赛记录是底片,身份是冲洗出来的照片**」「不只是记录,是把你『显影』成一个什么样的跑者」。
> - 用户旅程三步(2-verbal §334-336):**导入·聚合 → 显影·画像 → 峰值·被看见**;反派 =「**散落与遗忘**」(把完整生涯撕成无人读懂的碎片)。
> - 人格:智者(主)+创造者(次);克制、讲究、不替你尖叫。
>
> **这条疆域的核心赌注**:别的疆域把"显影"当一个 motif;**C 把它当整个视觉物理学**——所有元素都服从一条"从暗到亮、从模糊到清晰、从散落到成形"的成像定律。它是 01-foundation「档案绿」最锋利的对手,因为档案绿讲"沉淀后的凭证(已经显影完的结果)",而 C 讲"显影这个动作本身(被看见的发生过程)"——后者更贴 Purpose 的动词、更贴产品的命门时刻(完赛峰值那一下的"成像")。

#### 1. 一句话概念 + 如何回应设计原则

> **「身份,是从暗里冲洗出来的。」**
> 你跑过的每一场都先沉在暗处(散落、被遗忘的底片);Runprint 是那间暗房——把它们一张张冲洗、定影,让"你是一个什么样的跑者"在显影液里**渐渐浮现、对上焦、被看见**。

**如何回应设计原则:**

| 设计原则(源自战略/语言) | C 的回应机制 |
|---|---|
| **被看见 / 自我表达(命门)** | "被看见"不是一个静态状态,而是一个**显影动作**:界面、海报、主页都从一个偏暗的"未显影"态,在加载/生成/滚动中**冲洗出清晰的身份**。用户亲眼看着"这就是我"从暗里浮出来——自我表达被做成了一次仪式,而非一次渲染。 |
| **反派 = 散落与遗忘** | 视觉直接演这场对抗:**未聚合 = 暗、散、糊、欠曝**;**已聚合 = 显影完成、对焦、定影**。每导入一场完赛,画面就"多冲洗出一块"。遗忘 = 退回暗房;被看见 = 走出暗房。 |
| **可信 / 验证(智者)** | 显影是**化学/物理过程,不是魔术**——有明确的"定影(fix)"语义:一旦显影完成即锁定、不可篡改,呼应"去重验证、可追溯"。暗房的克制与精确(温度、时间、定影)天然带"实验室/裁判"的可信感,不是滤镜。 |
| **克制、不替你尖叫(智者主)** | 显影是**安静、缓慢、专注**的——红灯下的暗房,没有闪光、没有爆炸。整个体系靠"暗中缓缓亮起"产生力量,而非靠高饱和冲击。这正是"为你高兴但不替你尖叫"的视觉化。 |
| **创造者(次)** | 暗房是**手工冲印的工艺**(讲究、有手感、银盐颗粒、相纸边),把"把数据变成作品级画像"落成一种**冲印工艺美学**,而非数码生成感。 |
| **与跑步 App 区隔** | 跑步 App 的光是**向外炸的能量**(霓虹、速度线、燃烧);显影的光是**向内浮的显现**(从黑纸里析出影像)。同样用光,方向相反——这是最干净的区隔点。 |

#### 3. 色彩方向

**核心逻辑:深暗底是"未显影的暗房与底片",暖光高光是"正在析出的影像"。"从暗到亮"在空间和时间上同时发生——空间上,暗是背景、亮是被显影出来的主体;时间上,加载/生成时画面由暗转亮,就是"显影过程"本身。**

##### 底 · 暗房与底片(深暗,占画面 70–85%)

| 角色 | Hex 区间 | 说明 |
|---|---|---|
| 暗房黑(主底) | `#0E0F0D → #16140F` | 近黑,**带极微暖褐**(非纯黑、非冷蓝黑)——这是关键:暖向的黑读作"暗房/相纸",冷向的黑读作"科技/电竞"。 |
| 底片棕黑(次底) | `#1C1810 → #24201A` | 卡片/分区底,像未冲洗的胶片基,微微透褐。 |
| 显影液墨绿褐 | `#161C18 → #1E2A20`(克制) | **可选的与档案绿握手处**:深处带一点墨绿,是显影盘药液的颜色,不喧宾,埋个本土"路跑"暖意。 |

##### 浮现 · 渐次析出的光(从暗到亮的渐变带,是体系灵魂)

这不是一个色,是一条**显影曲线**——同一束暖光从"刚开始显影"到"完全定影"的渐变:

| 阶段 | Hex 区间 | 语义 |
|---|---|---|
| 欠曝/将显(最暗的亮) | `#5A4A33 → #7A6442` | 影像刚从暗里"将要"出现,模糊的暖褐 |
| 显影中(暖琥珀) | `#B08A4E → #C99A55` | 正在析出,银盐转出暖金 |
| 高光/已定影(暖象牙) | `#E8D6A8 → #F2E6C4` | 完成显影的相纸高光、被看清的身份 |
| 纯定影点(极少量) | `#FBF4E2` | 影像最亮处/对焦命中点,克制如点睛 |

> **为什么这条暖琥珀带不会滑向"霓虹燃烧":**
> - **低饱和 + 暖向 + 哑光**:显影的金是**银盐/相纸的暖**(像旧照片、像钨丝灯),饱和度压住(S 不超 ~55%);霓虹是高饱和、自发光、冷暖对撞。二者在 HSL 上分得很开。
> - **它从黑里"析出"而非向黑里"发射"**:渐变方向是 `暗→亮的浮现`(影像被冲出来),不是 `亮→暗的辉光`(能量向外炸)。同样是发光体,一个是"被显现的相纸",一个是"自燃的霓虹管"——观感截然不同。
> - **没有冷色撞色**:跑步 App 的燃烧靠"荧光绿/电蓝 + 橙红"的高对比撞色制造速度感。C **全程暖色单极**(暖黑→暖金→暖白),靠明度而非色相拉开层次——这是暗房真实的样子,也天然"慢、定、沉"。

##### 安全灯红(暗房专属点缀,极克制,< 3%)

| 角色 | Hex | 用法 |
|---|---|---|
| 安全灯红 | `#8C2D1E → #A8412B`(深、哑、偏砖) | **唯一的红**,只用于:CTA(保存/发布=把照片定影出来那一下)、"正在显影"的状态点。**深砖红、不鲜艳**——是暗房安全灯的红,不是警告红、不是燃烧红。 |

> CTA 用安全灯红的叙事:点下"保存海报" = 你在暗房里把这张照片**定影、印出来**。行动色和隐喻合一,且与全暖体系同源,不像档案绿方案里需要外接一个"窑火橙"。

##### 「散落→被看见」如何被色彩视觉化

- **散落态(未导入/加载中):** 元素压在暗房黑里,只有**欠曝级别的微光**勾边,彼此**不连、各自一小块**——读作"散落在暗处的底片"。
- **显影态(导入/生成中):** 暖琥珀沿元素边缘**由暗向亮爬升**,数据/画像**对焦清晰**——亲眼看着碎片被冲洗成形。
- **被看见态(完成):** 主体进入**暖象牙高光**,从暗底里完全浮出、定影锁定;周边仍是暗房黑——**暗不是背景,暗是"还没被看见的部分",亮是"已经被你证明的部分"**。生涯越完整,画面里被显影出的亮区越多——视觉直接等于护城河"聚合度"。

#### 4. 字体方向

> 智者的精确 + 暗房的工艺;成绩数字是"显影出的事实",必须最硬最准。

- **中文标题:** 带骨力的**现代宋**(思源宋 Heavy / 寒蝉端黑)——碑刻/相纸题字的庄重,在暗底上像**银盐压出的字**。比无骨黑体更贴"见证、履历"的分量。(此处与 01-foundation 候选不冲突,反而在暗底上更出效果——宋体的尖角在暖光里像被显影出的笔锋。)
- **中文正文:** 思源黑 / PingFang,克制、可读,暗底用偏亮字重避免发糊。
- **英文标题:** **Söhne / Neue Haas Grotesk**——瑞士理性,智者的精确底色。
- **成绩数字(命门):** **等宽 Tabular figures(Söhne Mono / IBM Plex Mono)**。这是"显影出的事实"——成绩册气质命门,数字永远对齐、永远等宽,像底片边缘的帧号/曝光数据,带一点点工业感。
- **工艺细节:** 关键标题/水印可叠**极轻的银盐颗粒纹理**(grain overlay),让字"长在相纸上"而非"贴在屏幕上"——这是 Creator 的手感,也是与数码冷光的分界。

#### 5. 形态 / 图形语言

**总纲:一切形态都是"成像过程"的物证。**

- **底片→正片(主母题):** 核心叙事单元。同一画像/数据可在**负片态(暗底亮线、反相)**与**正片态(亮纸暗字、冲洗完成)**间转化;导入/生成时从负片"翻正"——这是"散落记录(底片)→ 身份画像(照片)"语言隐喻的**直译**。
- **渐显梯度 / 显影边界:** 元素入场不靠位移飞入,靠**明度梯度从暗里浮出**(欠曝→对焦→高光)。卡片、数字、地图轨迹都用"显影锋面"扫过而出现。
- **银盐颗粒与层次:** 暗区有细腻**胶片颗粒**,亮区颗粒收敛——颗粒密度本身编码"显影程度"。营造"工艺/有手感",反数码塑料感。
- **光晕 = 浮影,不是辉光:** 主体周围允许极柔的暖光晕,但它是**相纸被照亮的反光**(向内、柔、暖、低对比),**严禁**做成向外放射的能量辉光。一个收一个放,这是与跑步 App 的形态分水岭。
- **网格成像 / 扫描显影:** 生涯长卷、城市足迹可用**逐格/逐行"显影出来"**的网格成像手法(像老式扫描/逐行冲印),把"聚合了 N 场"演成"N 格被逐一冲洗点亮"。**段位/百分位**这类智者数据,用"对焦标记 + 显影完成"的克制方式呈现,绝不做游戏化爆点。
- **相纸边 / 暗房物证:** 海报、卡片可带**相纸白边、底片齿孔、显影批注**等克制物证,强化"这是一张被冲印出来的东西",承接"印记/盖戳"情绪——但用**冲印语言**而非邮戳语言来表达(与档案绿的"邮戳子系统"形成不同路线的同一情绪)。
- **图标/Logo 走向(候选,公平竞争):** 母题可从「**显影中的同心圆 = 对焦环 = 跑道折返圈 = 正在成像的光圈**」——即把 01-foundation 的"同心环纹"重新解释为**相机光圈/对焦环在合焦的瞬间**,环从暗到亮收拢成形。这让档案绿的环纹母题在 C 里也能活,但被赋予"成像/被看见"的动作含义,而非"指纹/等高线"的静态含义。

#### 6. 影像 / 动效

> 动效是这条疆域的**主场**——因为"显影"本质是一个时间过程,只有动起来才完整。这是 C 相对档案绿(偏静态凭证)的最大杀伤力。

- **核心动效语法 = 显影成像(Develop-in):** 所有"出现"都是**从暗、从糊、从欠曝,渐次对焦、提亮、定影**。加载不是 spinner,是**一张正在被冲洗的照片**;数据不是数字跳动,是**数字从模糊里对上焦**。
- **完赛峰值的招牌时刻(命门动效):** 用户完赛/生成画像那一刻——**屏幕暗下(进暗房)→ 安全灯红微亮 → 你的身份画像/海报在显影液里由暗到亮缓缓浮现、对焦、定影"咔"地锁定**。这一下就是产品的"被看见仪式",安静、庄重、起鸡皮疙瘩,但**不尖叫**——智者的庆祝方式。
- **画像"显影成像"倾向:** 头像、城市足迹地图、生涯长卷都从**反相暗态扫描显影成正片**;等级/百分位数字**对焦析出**而非弹跳。整体节奏**慢而稳**(显影需要时间,慢本身是"讲究/可信"的语言)。
- **聚合的视觉:** 每多导入一场,画面**多冲洗亮一块**;"散落的暗块"被逐一显影连成完整生涯——动效直接演"收全"。
- **克制红线:** 无快闪、无粒子爆炸、无速度残影、无高频抖动。**唯一的"快",是定影锁定那一下的轻微"咔"**——其余全慢。

#### 7. 版式气质

- **暗场为纸,内容是被显影出的光。** 大面积暗房黑留白(留"暗"),内容区是被冲洗亮的岛屿——**negative space 在这里真的是"还没显影的负片区"**,留白有了叙事含义。
- **单焦点、高静默:** 每屏一个"已对焦"的主体(你的画像/这场成绩),其余压暗虚化——智者的克制,引导视线像引导对焦。
- **网格冷静、对齐严苛:** 成绩/数据走严格栅格、等宽对齐,像底片边缘的数据条;**冷静的工程感 + 暖的相纸感**并置,是"可信(理性)× 讲究(工艺)"的版式合奏。
- **层次靠明度不靠色块:** 信息层级用"显影程度(明度)"区分——最该被看见的最亮、最定影;次要信息停在欠曝档。整页像一张层次丰富的黑白照片被局部暖调上色。
- **物证点缀克制:** 相纸边、齿孔、批注只在海报/分享物上出现,App 内极简,避免"做旧滤镜"廉价感——讲究 ≠ 复古堆料。

#### 8. 适用场景:强 / 偏弱

##### 强场景

- **完赛峰值海报 / 分享主页(最强):** 深暗底 + 暖金浮现的画像,在小红书/朋友圈信息流里**一片亮色中是唯一一块"暗里发光"的**,极度跳脱、极度不像跑步 App,转发欲拉满。"显影出来的你"天然是好素材——直接服务冷启动 GTM(2-verbal §小红书钩子)。
- **完赛峰值那一屏(最强):** "显影成像"动效就是为这一刻生的,情绪峰值 × 仪式感 × 不尖叫,完美命中。
- **生涯长卷 / 城市足迹 / 年度回顾:** "逐格显影点亮"把"聚合了多少场"演成可感的成像过程,沉浸、有分量。
- **App 沉浸式身份页:** 暗场聚焦,智者气质,把"看清自己"做成专注体验。

##### 偏弱 / 需对冲场景

- **小红书封面缩略图(双刃):** 深色在信息流里**跳脱**是优点,但**缩略图发暗、暖金若压太低会"看不清主体"**是风险。对冲:封面必须保证有一块**高对比的暖象牙高光**作视觉锚点(已显影的脸/数字),不能整张闷在暗里。"暗中一束光"要够亮够聚焦。
- **功能型 / 工具型界面(导入、OCR 校正、设置):** 这些是"干活"的页,**全程暗房会累、会看不清表单**。对冲:**分场景调显影度**——身份/峰值页全暗房,工具/录入页**调到"已显影"的亮态(暖象牙底 + 暗字)**,即"走出暗房看成品"。暗与亮是同一套色的两端,切换自然不撕裂。
- **B2B/赛事方/品牌方物料:** B 端偏好清晰、专业、不情绪化。对冲:B 端用**"已显影完成"的亮态 + 数据栅格**为主,暗房叙事只做点睛,避免"太有情绪/太艺术"削弱可信。
- **App 图标小尺寸:** 暗底图标在桌面易"糊成一团黑"。对冲:图标用**亮态(暖金对焦环 on 暗,或反过来),保证小尺寸高对比可辨**。

| 风险 | 为什么会发生 | 如何拉回到"沉淀 + 人文" |
|---|---|---|
| **暗色 = 高冷电竞 / 科技感** | 暗 + 发光 = 赛博的默认联想;一旦黑偏冷、光偏霓虹、加 glitch,立刻滑向电竞。 | **三道闸:** ①**黑必须暖**(带褐,`#0E0F0D` 而非 `#0A0A0F`)——暖黑是"暗房/相纸",冷黑是"科技"。②**光必须低饱和、暖向、哑光**(银盐金,非荧光)。③**加银盐颗粒 + 相纸物证**——颗粒和纸感是"工艺/人文"的解药,数码冷光最怕"手感"。有颗粒、有纸边、有暖,就读"暗房";光滑、冷、自发光,才读"科技"。 |
| **暗调显得沉闷 / 压抑 / 丧** | 大面积暗 + 慢节奏,处理不好像"哀悼"而非"沉淀"。 | 靠**"浮现"的方向感**救:暗是"将要被看见",光在**往亮里走**——是希望的方向,不是沉下去。每屏必有一处明确的**暖高光"被看见"锚点**(你的脸/你的成绩定影成形),让暗有出口。沉淀 ≠ 沉没。 |
| **"显影"被做成一个滤镜噱头** | 当成 loading 特效贴一下,失去体系性。 | 把显影做成**贯穿的物理定律**(色彩=显影曲线、动效=成像、版式=负片留白、形态=底片翻正),而非单点动效。体系一致,才是疆域不是 trick。 |
| **暗房复古怀旧过头** | 相纸边/齿孔/做旧堆太满,变文艺滤镜 App。 | **克制物证**:App 内极简、只在分享物上点缀;现代宋 + Söhne + 等宽数字的**理性骨架**压住怀旧,做"当代的暗房",不是"复古的暗房"。智者的精确是怀旧的解毒剂。 |
| **可读性 / 无障碍**(暗底暖金对比不足) | 暖金中段 `#B08A4E` on 暗黑,正文易不达 WCAG。 | 正文/关键数据**必须用高段位高光**(`#E8D6A8`+)保证对比 ≥ 4.5:1;暖金中段只用于装饰性显影过渡、非正文。工具页直接切亮态。 |

#### 对位 01-foundation「档案绿」的一句话裁断(供评审)

> **档案绿讲"凭证已经在那里(沉淀完的结果,静态、可信、像档案馆)";显影讲"被看见正在发生(成像的动作,有时间、有仪式、像暗房)"。** 二者都能承载"沉淀/凭证/可信",但 **C 直咬 Purpose 的动词"被看见"和命门"自我表达"——它把"这就是我"做成一个用户亲眼见证其浮现的时刻**,这是档案绿(更偏静态结果陈列)给不出的情绪峰值。C 的代价是:暗色系工程化场景需做"亮态"对冲、无障碍要求更严。**两者并非互斥——最强组合可能是"档案绿的色性骨架 + 显影的动效与峰值语法",但作为独立疆域,C 以"成像动作"为轴,锐度和差异度高于把环纹/邮戳当静态装饰的路线。**

## 四、按设计原则打分 · 三 Territory 对比与推荐

> 用上面 5 条设计原则给三条 Territory 逐条打分(满分 25)。

| Territory | 一句话 | 总分 | 最强 | 风险 |
|---|---|---|---|---|
| **A 田野档案** Field Archive | 沉淀后的**静态凭证**——温暖、档案、证书感 | **20** | 温度 + 沉淀 + 凭证 | 偏静、偏复古;"绿"易滑向健康/活力,需色值体检 |
| **B 制式凭证** The Record/Ledger | 零情绪的**官方账本**——墨白、排版即可信 | **20** | 可信/克制天花板、与彩色跑步App彻底区隔 | 冷峻、弱自我表达情绪、缺人味 |
| **C 显影** Develop | 身份从暗中**被冲洗显现**——成像、被看见 | **22 ⭐** | 独占"显影"+"自我表达仪式"两根命门柱;直咬 Purpose 动词「被看见」 | 暗色易显"高冷电竞/科技",须拉回"沉淀+人文" |

**推荐:C 显影为主轴。** 它得分最高,且唯一把品牌核心隐喻(显影)与 Purpose 的动词(被看见)做成视觉主轴——散落→显影→被看见,与产品叙事同构。

**混血配方(若想兼得):C 主轴 + A 色性 + B 数字纪律** —— 用 C 的暗场显影成像做品牌签名动作,但借 A 的暖调(拉回人文、避免冷电竞),并守 B 的等宽数字与制式可信。

> **关于档案绿(A):它没有默认胜出,与对手并列 20。** 这是方法论的兑现——它若入选,要靠你按战略权重选择"沉淀温度"这条路,而非继承旧锚点。

## 五、视觉方向闸门(Gate)

**这是一道闸门:选定一条 Territory(或混血配方)之后,才启动 logo 发散 → 以 5 条设计原则收敛 → 精修 → 完整视觉识别(色彩/字体/图形/版式/动效)。**

一句话三选一(你更要哪种气质打底):
- **C 显影**——峰值情绪 + "被看见"的成像仪式(推荐主轴)
- **A 田野档案**——沉淀温度 + 证书收藏感(原档案绿,需色值体检)
- **B 制式凭证**——零情绪的官方权威 + 极致可信克制
- **混血**——C 主轴 + A 暖色性 + B 数字纪律
