# 一、六方向 · 设计说明(发散)



## 方向 · 显影印鉴 Seal

### logo 方向交付(疆域=显影 Develop · 母题=印鉴/钢印 × 暗房成像)

---

## 一句话概念

> **「一枚印鉴在暗中显影成形——你跑过的事实,从银盐的黑里被冲洗出来,落定成一枚只属于你的钢印。」**

印=身份+可信+仪式;显影=被看见的过程。品牌不盖这枚章,品牌只是冲洗它、见证它落定。

---

## 如何视觉化"显影/被看见"(疆域主轴,必须体现)

这是本方向的命门,用**四个可叠加的机制**把"散落 → 显影 → 被看见"做进静态标志里,而不只靠动效:

1. **银盐颗粒聚合成边**:印鉴的外缘不是一条干净的实线,而是由**离散的暖金颗粒点**在暗底上由疏到密聚拢成形——边缘外圈稀、靠主体密,肉眼读作"正在从噪点里析出"。这是"散点聚合成印"母题的静态固化。
2. **显影梯度(由暗到亮的单向浮现)**:整枚印从**左下/外缘的近乎隐没**到**右上/中心的完全显形**,走一道暖金→米白的明度梯度。不是装饰渐变,是"显影液正从这一侧漫过来"的方向感——读者的眼睛被引导着"看它显出来"。
3. **核心印面已落定、外缘仍在显影**:中心的钢印主形(印面)是**清晰、压凹、可核验**的完成态;越往外越溶解为颗粒。一枚标志里同时有"已成形的凭证"和"正在成形的过程"——这就是"被看见"的瞬间被定格。
4. **暗底是主角,光是被给予的**:深暗底不是背景,是暗房本身;暖金/米白是"被冲洗显现"的那部分。光从不铺满,只在印面落定处和高光棱上"被授予"——呼应原则四"这是你的印,不是我们的奖"(光是给跑者的,不是品牌的霓虹)。

> 一句话:**外缘在显影(颗粒/梯度),中心已落定(钢印/压凹),暗底给纵深,暖金给"被看见"。**

## 逐条对照 5 设计原则

| # | 原则 | 显影印鉴如何满足 / 不违反 |
|---|---|---|
| ① | **凭证感,不是仪表盘** | 主体是**钢印/印鉴**这一最纯粹的凭证物;闭合、压凹、有签发编号位,读作"被授予的印"而非"跳动的环形进度";绝无任何弧形进度、刻度跳动暗示。 |
| ② | **克制即权威** | 元素只有三样:**印面字 + 一道显影颗粒环 + 一束暖金高光**。两色(暗底 + 暖金/米白单一金属族),零撞色、大留白;靠"少"和"暗"立威,不喊。 |
| ③ | **显影,而非点燃** | 全部动态语义来自**由暗到亮的单向浮现 + 颗粒析出**(成形),没有任何放射、火焰、速度线、霓虹拖尾;暖金是"显影液漫过的光",不是"燃烧的光"。 |
| ④ | **这是你的印,不是我们的奖** | 印面中心**留给跑者的印记/段位/姓名缩写**(主角是跑者);Runprint 仅以极小骑缝编号/外环签发位出现在"见证人/签发方"位置,绝不占据印心;无桂冠(已出局),不自我表彰。 |
| ⑤ | **精确到可被核验** | 颗粒数、显影环的角度起止、压凹高光的棱线都按精确几何排布;印面带**签发编号位 + 骑缝刻线**;放大看每颗银盐点都在网格上,经得起检视。 |

| **核心亮点 1** | **静态里封装了过程**——一枚标志同时呈现"已落定的凭证"(中心钢印)与"正在显影的成形"(外缘颗粒/梯度),独占"显影"叙事,跑步 App 无人在此。 |
| **核心亮点 2** | **印心可个性化、品牌退位**——同一外壳,印心可换跑者缩写/段位/单场城市年份,天然长成**邮戳/认证/段位子系统**(接住"会成长"叙事),完美落原则四。 |
| **核心亮点 3** | **暗底单金属族,去色与小尺寸双稳**——去掉颜色后,钢印的压凹高光/暗影靠明暗即可成立(本就是单色显影);缩到 App 图标只保留印形+一道高光仍可辨。 |
| **适用场景** | App 图标(暗底版极稳)· 海报右下显影署名章/认证戳 · 公开主页头(印落定动效起手)· 实体周边压凹烫金 · 完赛单场邮戳(印心换城市年份)。 |
| **取舍与风险** | ① 颗粒/显影梯度在**极小尺寸(≤24px)会糊**——必须备一版"去颗粒、留实印+一道高光"的纯形 App 图标变体。② 暗底是基准,印在**纯白纸质媒介**上需翻成"压凹+旧金描边"的去暗底变体,否则显影叙事丢失。③ 暖金把控不当易滑向"奖牌金"——必须用**旧金/铜(哑光)**,非闪亮金,且只做高光不做填充。 |

## SVG 构图描述(关键 · 可照此矢量还原)

> 画布基准 `viewBox="0 0 240 240"`,所有坐标按此。中心 `C=(120,120)`。

### A. 暗底(暗房)
- 全画布圆角矩形或正圆暗底。**App 图标用圆角方**:`<rect x=0 y=0 width=240 height=240 rx=52>`,填充**径向渐变** `radialGradient` 中心 `(132,108)`:内 `#1E3A2A`(深档案绿)→ 外 `#11201A`(近黑墨绿)。这道偏心径向渐变本身就是"显影液从右上漫入"的暗房光。
- 可叠一层极淡噪点(`feTurbulence` baseFrequency≈0.9,opacity≈0.04)做银盐底噪,**仅大尺寸用,小尺寸删**。

### B. 主体钢印(印面 · 已落定)
- 主形=**正圆印 + 内嵌方印心**(圆=显影/暗房成像的"成像圈",方=钢印/凭证的"印面",圆方相济正合"印鉴")。
  - 外圆:`cx=120 cy=120 r=78`,**不画完整实线**——见 C 的颗粒环。
  - 内印心:圆角方 `x=78 y=78 w=84 h=84 rx=14`,**压凹效果**:用两条偏移描边模拟钢印——左上棱 `#FBF6E9`(米白高光,stroke-width 2.5)、右下棱 `#0E1710`(暗影,stroke-width 2.5),中间面 `#16241C`(比底略亮)。这就是"压进暗底"的钢印立体。
- **印心内容(主角位 · 跑者的)**:中央放一枚极简记号——推荐**一道"显影中的足印/对勾"或跑者姓名缩写**,用米白 `#F8F1DF`;此处是可替换槽(段位/城市/缩写)。记号笔画**右上端实、左下端化为 2–3 颗颗粒**,延续显影。

### C. 显影颗粒环(外缘 · 正在成形 · 疆域主轴)
- 沿外圆 `r=78` 的圆周布**离散圆点**(银盐颗粒),不是连续线:
  - 点半径 `0.8–2.4px` 不等,**靠右上密+大、靠左下疏+小**(显影方向);约 40–60 颗。
  - 颜色沿圆周做**角向渐变意象**:右上区 `#D4A85A`(旧金,完全显形)→ 顶/右 `#B68A3E`(暖金)→ 左下区淡出到 `#3A4A40`(几乎没入暗底,opacity 0.3→0.05)。
  - 实现:可用 `<circle>` 逐颗排布,或一条 `stroke-dasharray` 极碎的虚线圆 + `stroke` 渐变近似;**逐颗更可控、更"可核验"**。
- 颗粒环在**正右上方(约 1–2 点钟,起跑/显影方向)留一道更亮的金颗粒簇**作"显影最前沿"。

### D. 暖金高光(被授予的光 · 位置精确)
- **一束高光**,只一处,位于钢印**印心左上棱 (约 x=88,y=88 起,沿上棱与左棱)**:一条 2.5px 的米白→暖金渐变描边,模拟暗房灯打在钢印凸起棱上的反光。
- 中心记号上可点**一粒极小米白高光点**(`r=1.2`,`#FFFDF6`)在记号右上端——"显影完成的那一点亮"。
- 高光总占比 < 8% 面积。**绝不**在外圈做发光辉光(glow),只做"棱反光"。

### E. 签发位(可核验 · 品牌退位)
- 外圆与画布间的**下弧**,排一行极小骑缝刻线(短径向线 8–12 根)+ 一段微缩字 `RUNPRINT · 跑印`(沿弧 baseline,字高≈6px,旧金 50% 透明)。这是**签发/见证位**,克制、退居,放大才看清——正合原则五。

### F. App 图标极简版(怎么缩)
- 缩到 `≤48px`:**删颗粒环**(改为一道靠右上的 230°→320° 暖金实弧,stroke 4px,模拟"显影前沿"),**删骑缝字**,**保留**:暗底圆角方 + 压凹方印心 + 中心记号 + 左上一道高光棱。
- 缩到 `≤24px`:再删中心记号细节,只留**暗底 + 一枚压凹方印 + 右上一道暖金高光弧**——仍读作"暗中一枚印、被光点亮"。

### G. 去色版(怎么成立)
- 本方向**天生单色显影**,去色即把暖金族全部映射到**明度**:
  - 暗底→ `#1A1A1A`–`#111`(墨黑);印面棱高光→ 米白/纯白;暗影棱→ 纯黑;颗粒环→ 由白到透明的灰阶点。
  - 钢印的"压凹"靠**左上亮棱 + 右下暗棱**的明暗对比独立成立,不依赖任何颜色。
- **去暗底版(印在白纸)**:翻转为**纸白底 + 旧金/墨黑压凹印 + 颗粒改为压痕点**——显影叙事改由"油墨吃进纸/钢印压痕"承载,仍是"印鉴显形",不丢魂。

## 小尺寸 / 去色可辨性自评

| 维度 | 自评 | 说明 |
|---|---|---|
| **大尺寸(海报/主页头)** | ★★★★★ | 颗粒环 + 显影梯度 + 压凹钢印全开,叙事最完整,质感最稀缺。 |
| **中尺寸(48–96px App 图标)** | ★★★★☆ | 删颗粒、改一道暖金前沿弧后,**印形 + 压凹 + 高光**三要素清晰,辨识稳。 |
| **极小尺寸(≤24px favicon)** | ★★★☆☆ | **诚实短板**:颗粒/记号细节必糊,须切到"暗底 + 压凹方印 + 一道暖金高光弧"的纯形变体才成立——这版可辨但牺牲了显影颗粒。已在取舍中预留该变体,非临场补救。 |
| **去色(单色印刷/传真/水印)** | ★★★★★ | 本就是单色显影逻辑,压凹靠明暗、不靠色;去色后反而更纯,**最强项**。 |
| **去暗底(白纸/烫印实物)** | ★★★★☆ | 翻成"纸白 + 旧金压凹印 + 压痕点",显影叙事由油墨/压痕接管,成立且贴实体周边场景。 |

> 总评:**去色与暗底场景是这个方向的天然主场(单色显影血统);唯一需纪律守住的是极小尺寸必须切纯形变体、暖金必须哑光旧金不滑向奖牌金。** 在"显影"疆域内,它对主轴"散落→显影→被看见"的表达比环纹/字标路线更直给、更独占。

## 方向 · 等高线段位 Contour

> 上游：已签收战略 + 已过视觉闸门「显影 Develop / Darkroom」。本方向把"等高线"从地图测绘的静态符号，改造成**暗房里被冲洗出来的地形成像**——既是段位/海拔的身份层级，又是显影成形的动作本身。明确替代同心环、彻底去进度条化。

---

## 一句话概念

> **你的生涯是一座山——从暗里一层层显影出来的等高线，就是你的海拔（段位）；越往上、越亮、越被看见。**
> 散落的完赛记录是底片上欠曝的暗纹；Runprint 把它冲洗出焦，让"你跑到了哪个海拔"在暖金里逐层浮现、定影锁定。

---

## 如何视觉化"显影 / 被看见"（疆域主轴，必须体现）

这是判定成败的核心轴。Contour 用**三态成像**直译"散落 → 显影 → 被看见"：

| 态 | 视觉 | 语义 |
|---|---|---|
| **散落（未显影）** | 最外层、最低海拔的等高线**欠曝**：极暗的暖褐 `#5A4A33`，断续、虚、几乎没入暗房黑底——读作"还没被冲洗出来的山脚底片" | 散落与遗忘 = 暗、糊、断 |
| **显影（正在成形）** | 从外向内、从低到高，等高线**逐层提亮、由虚转实**——欠曝褐 → 暖琥珀 `#C99A55` → 暖象牙 `#F2E6C4`。明度梯度本身就是"显影锋面"扫过山体 | 冲洗中、对上焦、银盐转金 |
| **被看见（已定影）** | **最高处的山顶等高线 + 顶点对焦命中点**进入纯定影暖白 `#FBF4E2`，完全从暗底浮出、定影锁定——这是"你这个海拔被证明、被看见"的那一点 | 走出暗房、身份成像 |

关键机制：**亮 = 已被显影出的海拔，暗 = 还没到达的海拔。** 跑者段位越高，被点亮的等高线层数越多、山越亮越高——视觉直接等于"段位/聚合度"。这让"显影"不是一层滤镜，而是 logo 的成像物理学：暗不是背景，暗是"你还没爬到的部分"。

去进度条化的关键：等高线**不闭合成同心环、不等距、不绕圈**——它们是**地形剖面线**（仿真实地图等高线的不规则起伏 + 一个明确的山峰偏心顶点），眼睛读到的是"一座山的海拔层"，而非"一圈一圈的进度/仪表盘/音波"。

## 逐条对照 5 设计原则

| # | 原则 | Contour 如何满足 |
|---|---|---|
| **①** | **凭证感，不是仪表盘** | 等高线是**地形测绘语言**（剖面层 + 海拔标高），不闭环、不走圈、无刻度指针——天然脱离仪表盘/进度环；山顶旁可挂一枚克制的"海拔标高数字"（tabular figure），像测绘图上的高程注记，是凭证不是 KPI。 |
| **②** | **克制即权威** | 元素只有两类：一组等高线 + 一个对焦顶点。无字、无框、无装饰。暖色单极（暗黑→暖金→暖白），靠明度而非配色拉层次，留白（暗场）占 70%+。 |
| **③** | **显影，而非点燃** | 海拔从**暗里逐层析出**（暗→亮的浮现），不是向外炸的辉光；用"地形成像"而非"火焰/速度线"。运动感来自"一层层成形/登顶"，不来自加速燃烧。 |
| **④** | **这是你的印，不是我们的奖** | 主角是**这座山的形状**——每个跑者的山（段位/履历）不同；Runprint 只提供"冲洗"的暗房，品牌退到签发位（字标另置，符号本身不喊品牌）。无桂冠、无奖杯，海拔=自我证明而非颁奖。 |
| **⑤** | **精确到可被核验** | 等高线间距、顶点坐标、标高数字都是**可量化的测绘几何**；放大后线宽递变、颗粒收敛、对焦点命中——细节经得起放大，像一张真实的地形剖面图而非装饰花纹。 |

## SVG 构图描述（关键 · 可照此矢量还原）

**画布与坐标**：`viewBox="0 0 240 240"`。所有几何以此 240×240 网格描述。圆形安全区半径 110（居中 120,120），主体落在中央 200×200 内。

### 0. 暗房底
- 满幅圆角方/圆底，填**暗房黑径向渐变**：圆心 `(120,150)`（略偏下）为 `#16140F`，边缘 `#0E0F0D`。这是"暗房与未显影的底片"，占画面 75%+。
- 极轻**银盐颗粒**叠加（`feTurbulence` 做的噪声，opacity ≈ 0.04，暗区略重、亮区收敛），让线"长在相纸上"。

### 1. 主体：一组显影地形等高线（共 6 层）
核心是**6 条不闭合、不等距、由低到高的地形剖面线**，共享一个偏心山峰顶点 `P = (132, 72)`（**偏右上**，制造一座有方向感的山，而非对称圆）。

- **形态**：每条线是一条**平滑贝塞尔曲线**，横跨画布左缘到右缘（约 x=30 → x=210），中部隆起成峰、两侧落下成坡——像真实地形图的一条等高线被"切开摊平"。各层**不平行、不等距**：越靠山顶层间距越小（陡），越靠山脚层间距越大（缓），符合真实等高线读法。
- **6 条由低到高（L1 最低最外，L6 最高最内/最靠顶点）**，建议控制点骨架：
  - **L1**（海拔最低，y 基线 ≈ 188）：浅缓大弧，峰部仅微抬到 y≈150。
  - **L2**（基线 ≈ 168，峰 y≈128）
  - **L3**（基线 ≈ 150，峰 y≈108）
  - **L4**（基线 ≈ 134，峰 y≈92）
  - **L5**（基线 ≈ 120，峰 y≈80）
  - **L6**（基线 ≈ 108，峰 y≈74，最贴顶点 P）
  - 每条用 `path` 的 `C`/`Q` 平滑过峰，峰顶 x 统一对齐到 **x≈132**（偏右），使 6 层叠出一个**右上偏心的山形**。

- **显影渐变（灵魂）**：6 条线的**颜色与不透明度从 L1 到 L6 逐层提亮**，直译"由暗到亮的显影锋面"：

| 线 | 描边色 | 描边宽 | opacity | 状态语义 |
|---|---|---|---|---|
| L1 | `#5A4A33`（欠曝暖褐） | 1.4 | 0.45 | 将显·几乎没入暗底 |
| L2 | `#7A6442` | 1.6 | 0.60 | 欠曝 |
| L3 | `#9A7B46` | 1.8 | 0.78 | 开始析出 |
| L4 | `#B08A4E` | 2.0 | 0.90 | 显影中·暖琥珀 |
| L5 | `#C99A55` | 2.2 | 1.0 | 接近定影 |
| L6 | `#E8D6A8 → #F2E6C4`（沿线性渐变，左暗右亮） | 2.4 | 1.0 | 已定影·暖象牙高光 |

  - 描边统一 `stroke-linecap="round"`，`fill="none"`。
  - **递变本身就是"显影"**：眼睛从外（暗、虚、细）扫到内（亮、实、粗），读到的是"这座山正被一层层冲洗出来，越高越被看见"。

- **断续欠曝处理（强化散落→显影）**：L1、L2 不画成连续整线，而是用 `stroke-dasharray`（如 `"6 5"`、`"10 4"`）做成**断续虚线**——最低海拔像"还没被显影连起来的底片暗纹"；L3 起逐渐变实线（dasharray 取消）。**越低越断、越高越连**，把"散落→聚合成形"做进线本身。

### 2. 对焦命中点（被看见的那一点）
- 在山峰顶点 `P=(132,72)` 放一枚**实心暖白圆点**，r=3.2，填 `#FBF4E2`（纯定影点），外加一圈极柔的**向内浮影**（径向渐变光晕 r≈10，`#F2E6C4` → 透明，opacity 0.35）——注意是**向内的相纸反光，不是向外的能量辐射**（P3 分水岭）。
- 点的左上/右下可选挂**两道极短的对焦角标**（各长 4px 的细线，`#E8D6A8`，宽 1），像相机对焦框合焦命中——克制地暗示"对上焦了、定影了"。这是"被看见"的视觉句号。

### 3. 暖金高光位置（光从哪来）
- **高光集中在山顶 + 顶点右侧**（L5、L6 的右半段 + 对焦点）——模拟暗房里影像"从最该被看见处先析出"。
- L6 用**线性渐变描边**：x=70 处 `#E8D6A8` → x=170 处 `#F2E6C4`，使**右上最亮、左下渐暗**，给出统一光向，避免平涂死板。
- 整体暖金 S 压在 55% 以内、哑光，**绝不加 glow/blur 外发光**——浮影只用低对比径向渐变，不用 `feGaussianBlur` 做霓虹辉光。

### 4. 可选海拔标高（凭证细节，P5）
- 在山顶右侧、对焦点旁，挂一枚极小的 **tabular 数字 + 单位**（如等宽字体 `42.195` 或段位代号），字色 `#C99A55`，字号 ≈ 9，像地形图上的高程注记/底片帧号。**仅完整版用，App 图标版去掉。**

### App 图标极简版（如何缩）
- **降到 3 层等高线**：只保留 L2(暗)、L4(中)、L6(亮高光) + 顶点对焦白点。去掉断续 dasharray（小尺寸虚线会糊），三条都画实线，但**保留由暗到亮的明度梯度**——这是不能丢的"显影"信号。
- 描边整体加粗 ~25%（L6≈3、L4≈2.6、L2≈2.2）保证 16–32px 仍可辨。
- 去掉海拔数字、去掉对焦角标，只留**三层山形 + 顶点暖白点**。轮廓识别：暗底 + 偏右上的暖金山形 + 一个亮点 = 一眼"被显影出的一座小山"。
- 底用暗房黑径向底，圆角约 22%（iOS）。

### 去色版（如何成立）
- 去色后**全靠明度梯度**承担全部层级——这正是本方向的先天优势（暖色单极、本就靠明度不靠色相）。
- 6 层映射为 6 档灰：L1 ≈ #4A4A4A（最暗）逐层到 L6 ≈ #F2F2F2（最亮）+ 顶点纯白 #FFFFFF。
- 暗底转 #161616；颗粒保留。由暗到亮的"显影"叙事**完全保留**，断续→连续、低→高、暗→亮三条线索都不依赖颜色。
- 单色正片版（浅底）：暗房黑底翻成暖米白 `#F6EEDD`，等高线翻成单一墨色 `#1A1A1A` 由淡到浓（低层淡墨、高层浓墨 + 顶点实心墨点）——即"底片态→正片态"的翻正，海报压印/烫金场景用。

## 方向 · 邮戳钢印 Postmark

---

## 一句话概念

**一枚从暗房药液里浮现的骑缝邮戳——你跑过的那一刻，被盖下、被签发、被见证；而显影未完，戳记正自暗中成形。**

英文锚点：*Postmarked the moment you finished. Developing into proof.*

---

## 如何视觉化"显影 / 被看见"（疆域主轴）

戳记不是"印好放在那里"，而是**正在被显影出来**——这是本方向的命门。三层手法：

1. **半显的戳圈**：邮戳的外环不是一条完整实线，而是从 7 点钟方向起、顺时针由"几乎看不见的暗"渐变到"暖金实成"，约 300° 处达到最亮，最后 60° 又隐回暗底。整圈是一次"显影的进度",但不是进度条——它是光在药液里爬过金属边缘的痕迹。
2. **骑缝断口**：戳被一条看不见的"骑缝线"(纸张接缝)垂直切过，左半已显影成形、右半仍是散落的银盐颗粒尚未聚拢。骑缝＝跨越的那一步，断口即"正在被盖下"的瞬间。
3. **颗粒成戳**：戳的核心字符/标记由暗房颗粒"聚拢"而成——边缘颗粒松散、中心凝实，传达"从散落到成印"。

关键体感：看第一眼是一枚戳；多看一秒，发现它**正在浮现**，而非已完成。这正是"签发·见证"的时态——见证一个**正在被确认**的事实。

---

## 逐条对照 5 设计原则

1. **凭证感，不是仪表盘** ✅ 邮戳/钢印是"签发凭证"的最强原型，骑缝＝防伪接缝，天然是 proof 而非 metrics；无任何数值、环形进度、百分比。
2. **克制即权威** ✅ 单一圆戳 + 一条骑缝断线 + 内部一个极简标记，三件套；配色仅暗底 / 暖金 / 米白三色，大量留白（戳外即纯暗底）。
3. **显影，而非点燃** ✅ 亮度是"渐显"曲线（暗→暖金），是光"爬过"金属边缘的成形过程，没有任何放射、拖尾、燃烧、速度感；时态是"正在成形"不是"正在加速"。
4. **这是你的印，不是我们的奖** ✅ 戳是**盖在跑者完赛事实上的签发动作**——主角是"被盖下的那一步"，品牌是握章签发的见证人，退在戳的形制里，不喧宾夺主；绝无奖杯/桂冠。
5. **精确到可被核验** ✅ 骑缝断口、颗粒密度梯度、戳圈缺口角度都是"经得起放大"的真实工艺细节；放大后看到的是钢印压痕的精确，不是模糊光晕。

## 去色版（单色怎么成立）

- **正去色（暗底）**：全部元素转为单一米白 `#EDE6D8`，靠**透明度分层**还原显影梯度——戳圈左半 90% 不透明、右半 45%；颗粒 20–60%；骑缝线 25%。结构（戳圈 + 骑缝断口 + 等高线芯）完全不依赖颜色，纯靠形与透明度成立。

## 一句话概念

**「跑印」二字本就不在那里——它由暗房里散落的银盐颗粒，被显影液逐粒析出、对上焦、定影成形：你看到的不是一个被印上去的字，而是一个正在被冲洗出来的身份。**

英文落款 Runprint 同理：字母的笔画是颗粒的聚集密度，不是描边。

## 如何视觉化「显影／被看见」（疆域主轴，必须体现）

这是本方向的命脉，落在四个可被矢量还原的机制上：

1. **颗粒密度梯度 = 显影程度。** 字形不靠实心笔画定义，靠**点阵（银盐颗粒）的疏密**定义。字的核心笔画区颗粒最密、最亮（已定影）；笔画边缘颗粒渐疏、渐暗（正在显影）；字外的暗场散布极稀的欠曝微粒（还没被冲洗到的部分）。**密→稀就是亮→暗、聚→散、被看见→被遗忘**——一张图同时演完整条显影曲线。

2. **左暗右亮的「显影锋面」。** 整个字标存在一条隐形的**显影扫描线**（从左下向右上）：左侧／起笔处颗粒偏欠曝暖褐 `#7A6442`，过渡到中段暖琥珀，到右侧／收笔处进入暖象牙高光。读起来字是「正从这一侧被冲出来的」，天然有方向感和时间感——浮现，而非静止地印着。

3. **暗底「析出」而非亮底「印压」。** 主体永远生在暗房黑上。字不是盖在底上的深色印记，而是**从黑里被提亮析出的光**。这是与「档案绿／邮戳」路线最干净的分界：邮戳是「压进纸里（亮底暗字）」，银盐是「从暗里浮出来（暗底亮字）」。

4. **一个「对焦命中点」。** 全图只有一处 `#FBF4E2` 纯定影点（落在「印」字的口部收笔，或 R 的接缝），克制如点睛——它是「对上焦了、定影锁定」的那一下，是整张图最亮、颗粒最实的一粒，给暗场一个明确的「被看见」出口，避免整图闷在暗里。

## 逐条对照 5 设计原则

| # | 原则 | 本方向如何满足／不违反（一句） |
|---|---|---|
| ① | **凭证感，不是仪表盘** | 字标是「一张被冲洗出的相纸」，无环、无弧、无刻度、无进度条——根本没有可被读成仪表盘的元素。 |
| ② | **克制即权威** | 元素只有三样：字、颗粒、一条隐形显影锋面；全暖单极色（暗黑→暖金→暖白），靠明度而非色相分层，留白即「未显影的负片区」。 |
| ③ | **显影，而非点燃** | 颗粒是「向内析出」（从黑里被冲出来），不是「向外发射」（能量辉光）；低饱和暖琥珀（S≤55%）、哑光、银盐质感，与霓虹／火焰在 HSL 上整象限隔开。 |
| ④ | **这是你的印，不是我们的奖** | 主体是「跑印／你的字」本身，品牌只做那只「把它冲出来的暗房之手」——无桂冠、无奖杯、无品牌图腾凌驾于字之上。 |
| ⑤ | **精确到可被核验** | 颗粒是**规则化的点阵**（不是随机噪点），密度按显影曲线精确编码；放大后每一粒都站得住，字形骨架是工整的现代宋／几何无衬线，经得起 4× 检视。 |

## SVG 构图描述（关键 · 可照此矢量还原）

> 画布与坐标以横版主字标为基准；中文「跑印」+ 英文「RUNPRINT」上下锁版。所有坐标基于 `viewBox="0 0 1200 480"`。

### 0. 底与全局

- **背景**：全幅矩形 `#0E0F0D`，叠一层径向暗角（中心 `#16140F` → 四角 `#0B0C0A`），制造「暗房中心被安全灯照到」的纵深。不画相纸边（App 内极简，相纸齿孔只在海报变体加）。
- **显影锋面（隐形参考轴）**：一条从左下 `(180,360)` 到右上 `(1040,140)` 的对角线。它不可见，但**所有颗粒的亮度／密度沿其法线方向插值**：越靠左下越暗越疏（欠曝 `#7A6442`），越靠右上越亮越密（高光 `#E8D6A8`）。这是「字正从左下被冲到右上」的成像方向。

### 1. 中文主体「跑印」（占视觉重心，居中偏上）

- **字形骨架**：带骨力的**现代宋**（思源宋 Heavy 气质），横细竖粗、尖角锋利。两字总宽约占画布 58%（约 700px），高约 220px，水平居中，垂直放在画布上 55% 处。**字标主导，这是全图主角。**
- **关键：笔画不是实心填充，而是颗粒点阵。** 实现逻辑——
  1. 先以现代宋取「跑印」二字的**实心矢量轮廓**作为「显影遮罩（mask）」。
  2. 在遮罩内铺一层**规则六边形／正交点阵**（圆点半径 `1.6–3.2px`，行距 `~7px`），即银盐颗粒层。
  3. 每个颗粒的**填充色与不透明度**由它在「显影锋面」上的投影位置决定：
     - 笔画核心轴线附近 + 锋面右上侧 → 颗粒最密（行距收到 5px）、最大（r=3.2）、最亮（`#E8D6A8`，opacity 1）。
     - 笔画边缘 + 锋面左下侧 → 颗粒渐疏（行距放到 9px）、渐小（r=1.6）、渐暗（`#B08A4E → #7A6442`，opacity 0.5→0.85）。
  4. **笔画边缘做「显影羽化」**：轮廓不是硬切，而是颗粒密度向外衰减约 6–10px 后归零——字边像在显影液里「正在长出来」，不是被裁刀切出。
- **暖高光位置**：「印」字右侧／收笔的竖与口部，落在锋面最右上，颗粒最密最亮；在「印」字**口部右下收笔**点一粒 `#FBF4E2` 纯定影点（直径 ~5px，周围一圈极柔暖光晕 `#F2E6C4` opacity 0.3，向内反光，不向外放射）——这是全图唯一对焦命中点。

### 2. 字外暗场颗粒（散落 → 聚合的视觉证据）

- 在「跑印」二字**周围的暗场**，散布极稀疏的孤立颗粒（r=1–1.6，`#5A4A33`，opacity 0.2–0.4），数量随离字距离增加而锐减。
- 这些颗粒**越靠近字越密、越向外越散**，仿佛字是「颗粒被显影液吸引、聚拢、对焦」的结果。左下方向（锋面起点）可多留几粒「还没被冲到」的欠曝散粒，右上方向几乎无散粒（已全部定影进字里）。**这就是「散落 → 显影 → 被看见」在静帧里的全部证据。**

### 3. 英文落款「RUNPRINT」（横向锁在中文下方）

- 字体 **Söhne / Neue Haas Grotesk**，全大写，字间距放宽（tracking +120），字号约为中文高度的 18%，水平居中于「跑印」正下方约 40px 处。
- 同样用颗粒点阵构成（颗粒更细 r=0.8–1.6，因字小），同一条显影锋面：左侧 `RUN` 偏暖琥珀略欠曝，右侧 `PRINT` 进暖象牙——**英文也在被同一束显影液从左往右冲出来**，与中文同源同律。
- 可选：在 `RUNPRINT` 下方加一条**极细的「显影批注线」**（1px，`#5B6660`，居中限宽），像底片边缘的曝光数据条——承接「成绩册／底片帧号」的工艺细节，克制不抢戏。

### 4. App 图标极简版（小尺寸怎么缩）

> 颗粒在小尺寸必糊，故图标**放弃全字标，提取「印」的偏旁或单字母 R 做几何实体化**，但保留显影方向感。

- 画布 `1024×1024` 圆角方（iOS）／圆（Android），底仍是暗房黑 `#0E0F0D` 径向暗角。
- 主体二选一：
  - **方案 A（推荐）**：单字「**印**」的极简骨架，或其右半「卩」的章形钩，**实心填充**但保留**左下暗 → 右上亮**的线性渐变（`#7A6442 → #E8D6A8`），右上收笔处点一粒 `#FBF4E2` 定影点。一笔成形，16px 仍可辨。
  - **方案 B**：字母 **R**，竖画 + 腿做成几何实体，同一左暗右亮显影渐变。
- **颗粒在图标里的存活方式**：不铺满字（会糊），只在**主体左下侧边缘**留 5–8 颗清晰可数的大颗粒（r 相对画布 ~2.5%），点出来「这是颗粒显影出来的」DNA，其余实体化。**保证 16–24px 缩略仍是高对比的「暗底一束暖光」**。
- 颗粒过密风险已规避：图标层颗粒数 < 10，每一粒都数得清。

### 5. 去色版（单色怎么成立）

- **逻辑不变，把「色相」全部换成「明度」**——这正是银盐黑白照片的本来面目，去色版反而是它的「原生态」。
- 底：纯暗灰 `#141414`（或印刷正片用纸白 `#F4F1EA`，走「已显影正片」亮态）。
- 颗粒／字：单一中性色（暗底版用暖白 `#ECE6D8`，亮底版用墨黑 `#1A1A1A`），**全靠颗粒密度 + 明度梯度**表达显影：核心密而实、边缘疏而淡、左暗右亮的锋面用「颗粒疏密」即可表达，无需任何颜色。
- 定影点：去色版仍保留——它是密度最高、唯一 100% 实的那一粒，对焦命中感不依赖颜色。
- **实体周边压印**（金属铭牌／硬卡）：用亮态正片版，颗粒做成实际的**网点凹印**，去色后即真实的「银盐网点」——质感和概念在物理介质上自洽。

## 一句话概念

**散落各处的完赛,像银盐在显影液里向心聚拢,凝成一枚浮现于暗底的印——你跑过的每一步,都在这里被冲洗显现、被看见。**

---

## 如何视觉化"显影/被看见"(疆域主轴)

这是整个方向的灵魂,用三层叠加表达,缺一不可:

1. **空间维度——向心聚合**:外圈是松散、低透明度的散点(代表散落各地、尚未被记录的完赛);越向中心,点越密、越亮、越靠拢,最终在中心咬合成一枚清晰的实体印记。视线被"吸"向中心,这就是"散落 → 聚合"。

2. **明度维度——从暗中浮现**:整枚标志不是"画上去"的,而是**从深暗底里渐渐显影出来**。中心印记最亮(已显影完成),外圈散点最暗(刚入显影液、尚未成像)。用明度梯度模拟银盐照片在红光暗房里"图像慢慢浮起"的瞬间——这就是"被看见"的字面视觉。

3. **完成度维度——半显影的张力**:刻意让最外环的几个点停在"将显未显"的临界态(虚边、半透),暗示**显影正在发生、尚未凝固**。这制造了"此刻正被冲洗"的现在进行时,而非一个已完工的死标。被看见 = 一个动词,不是一个状态。

> 关键判定:遮住中心印记,只看外圈,应该读出"一群正在汇聚的微光";遮住外圈,只看中心,应该读出"一枚可签发的实体印"。两端都成立,中间是连续的显影梯度。

## 逐条对照 5 设计原则

| 原则 | 它如何满足 / 不违反(一句) |
|---|---|
| **① 凭证感,不是仪表盘** | 中心是一枚边界清晰、可"盖下去"的实体印记(钢印/印鉴质感),不是环形进度、不是数据环——它是身份印章,不是读数面板。 |
| **② 克制即权威** | 全标只有三种元素(散点 / 中心印 / 一道暖金高光),双色无渐变堆砌,大面积暗底留白;少到无可再减。 |
| **③ 显影,而非点燃** | 用明度从暗到亮的"浮现"梯度成形,运动方向是**向心聚拢凝固**,而非向外发散燃烧;没有任何拖尾、光芒、热感。 |
| **④ 这是你的印,不是我们的奖** | 主角是聚合而来的"那些步数/那些完赛"(散点=跑者的轨迹),中心印是跑者自己的身份印;品牌只提供"显影液/暗房"这个容器,退居见证位。 |
| **⑤ 精确到可被核验** | 散点数量、间距、明度分级都按规则排布(下文 SVG 有精确网格),放大后每个点边缘干净、印记内部结构经得起细看,非随机噪点。 |

## 《设计说明》

**方向名**:显影印 / Develop-Print(隶属疆域:显影 Develop)

**风格说明**:暗房银盐显影质感。深暗底(近黑墨蓝)+ 暖金主印 + 米白散点的双层渐次浮现。极简几何,无插画、无字体化主体,主体即"点 → 印"的形态转换本身。

**设计思路**:把品牌核心叙事"散落 → 聚合 → 被看见"压缩进**一个连续的向心明度梯度**里。外圈散点 = 散落的完赛;向心收拢 = 聚合;从暗到亮的浮现 = 被看见/显影。不靠隐喻拼贴,靠"一个动作"直接成像——这是它比"印鉴+邮戳"等组合方案更高级的地方:它本身就是显影这个动作的定格。

**核心亮点**:
1. **概念=形式高度统一**:聚合的几何运动本身就是品牌叙事,无需文字解释即可读出"汇聚成印"。
2. **显影梯度是独家资产**:从暗底浮现的明度过渡难以被竞品(燃烧系跑步App)模仿,天然反霓虹。
3. **可动**:聚合是天然的入场动画(散点由外向内、由暗到亮逐帧显影成印),App 启动 / 完赛弹窗 / 海报署名都能复用同一动作。

**适用场景**:App 图标(中心印单独成立)· 海报水印署名(去色单色版)· 公开主页头(全显影梯度大图)· 实体周边(中心印烫金 / 钢印压凹)。

**取舍与风险**:
- 取:放弃了"一眼即懂的具象符号"(如脚印/印章图案),换取了概念深度与不可模仿性。
- 舍:散点过多会滑向"星空/粒子特效"的科技感俗套——**必须严格限点数(≤24)、限明度档(3档)**,否则失控。
- 险:小尺寸下外圈最暗的散点可能丢失。对策:App 图标版直接舍弃外圈,只保留中心印 + 一圈贴身的高亮收口点(下文有缩法)。
- 险:与"散点聚合成印"母题的其他比稿撞型。差异化锚点 = **明度显影梯度**(别家做聚合多用等大同色点,我们用从暗到亮的浮现分级)。

**推荐度**:★★★★☆(4.5)。概念最贴疆域主轴、最反俗套;唯一扣分项是对执行精度要求高,点阵排布与明度分级须像素级调校,容错低。

## SVG 构图描述(可照此矢量还原)

**画布与坐标**:`viewBox="0 0 200 200"`,几何圆心 `C=(100,100)`。所有元素相对圆心极坐标排布。

**底色**:全画布填充深暗底 `#0E1217`(近黑、微冷蓝墨),作为暗房底。所有"浮现"= 在此底上叠加不同明度的暖金/米白圆点。

**三同心环带 + 一中心印,共四层(由外到内,明度由暗到亮——这是显影梯度的物理实现):**

**第 4 层(最外环 · 将显未显)**
- 半径 `r=78`,沿圆周均匀放 **12 个点**(每 30°一个,起始角 -90°)。
- 点直径 `2.2`,填充米白 `#EDE6D6`,**透明度仅 0.18~0.28**(可让其中 3 个掉到 0.12,造"个别尚未浮起"的不齐感)。
- 作用:暗示散落、刚入液、最弱的显影。小尺寸下这一层是第一个被牺牲的。

**第 3 层(中环 · 显影中)**
- 半径 `r=56`,放 **8 个点**(每 45°,起始角 -67.5°,与外环错开成梅花交错,不要径向对齐)。
- 点直径 `3`,米白 `#EDE6D6`,透明度 `0.45~0.6`。
- 作用:聚合进行时,明度已起。

**第 2 层(内环 · 即将咬合)**
- 半径 `r=34`,放 **6 个点**(每 60°,起始角 -90°)。
- 点直径 `3.6`,色由米白偏向暖金过渡 `#E8C87A`,透明度 `0.8~0.95`。
- 作用:最贴近中心印的一圈,几乎已成像,色温开始转金——视觉上"被印记吸住"。

**第 1 层(中心印 · 已显影 · 主角)**
- 一枚**实体印记**,占据中心,外接半径约 `r=22`(直径约 44,占画布 22%)。
- 形态:**钝角六边形钢印轮廓**(六边形呼应外圈的环形对称,又比圆更有"被压制成型"的钢印硬度;避免用圆以免读成进度环)。六边形顶点圆角 `2`,描边 `2.4` 暖金 `#E8C87A`,内部不满填,留暗底(空心印章感,像盖印后的轮廓)。
- 印心:六边形正中一个**实心小圆点 `r=4`**,纯暖金高光色 `#F2D58C`——这是全标最亮点,即"显影完成的核",也是视觉锚。
- 可选内构(增强可核验性、放大耐看):六边形内沿一圈极细 `0.6` 的同形内描边(骑缝/钢印双线感),颜色 `#E8C87A` 透明度 0.5。

**暖金高光位置(单一光源,克制)**
- 想象光从**左上 315° 方向**斜射入显影盘。在中心印的**左上弧段**(约 120°~210°方位)把六边形描边提亮为 `#F2D58C`(高光金),其余弧段维持基底金 `#E8C87A`——形成一道沿印章轮廓滑过的高光,赋予"从暗中被照亮、立体浮起"的体积感。
- 内环(第2层)朝左上的 2 个点也轻微提亮,呼应同一光源。**全标仅此一处高光逻辑,不再有第二光源。**

**整体显影氛围(可选叠加,印刷/数字大图用)**
- 在中心区叠一个极淡的**径向暖光晕**(`radialGradient`:圆心 `#E8C87A` 透明度 0.10 → 边缘 0 透明,半径 60),模拟显影液中图像周围的微光浮起。小尺寸/去色版**去掉此晕**。
- 可叠一层 1~2% 的细颗粒噪点纹理(银盐颗粒),仅大图开启。

**App 图标极简版(缩法)**
- **直接砍掉第 3、第 4 层(中外两环散点全删)**。
- 只保留:中心六边形钢印 + 印心高光圆点 + **第 2 层内环 6 点**(作为贴身收口,暗示"刚聚合完")。
- 中心印相对放大到外接 `r=30`,六边形描边加粗到 `3.2`,确保 `48×48 px`、`16×16 px` 下印心高光点与六边形轮廓都清晰可辨。
- 底仍为 `#0E1217`,印为暖金——暗底金印,在一排亮色App里反而跳出、显贵。

**去色 / 单色版(海报水印、压凹、烫印)**
- 全部改为**单色 = 暖金 `#C9A86A` 或纯黑/纯白**,靠**透明度梯度**而非色相区分层次:外环 0.2 / 中环 0.5 / 内环 0.85 / 中心印 1.0。
- 显影叙事在纯单色下依然成立——因为它从一开始就是用"明度/透明度浮现"而非"颜色"讲故事的。这是本方向去色不垮的根本原因。

## SVG 构图描述（可照着矢量还原）

**主体形状 · 显影窗**
- 一枚正圆"显影窗"，直径占画布主体。底为 `windowBg` 线性渐变（顶 `#1C1813` → 底 `#0C0A07`），近黑而暖。窗边两道描边：外圈 `#7A5A2E` 1.5px（暖金窗框），内圈 7px 处一道 `#5A431F` 0.6px 虚线（`dasharray 2 4`）= 骑缝/钢印的暗角缝。整窗用 `circClip` 裁切，内部所有元素不出框。

**构成元素 · 三样，无其他**
1. **银盐颗粒底噪**：窗内散布约 15 个 `#5A4A30`、r≈1 的小圆点，`opacity 0.5`，是"尚未显影"的底片质感。
2. **跑者足印（主角印记）**：一条足底轮廓 `path`，鞋床由脚跟（下）收到前掌（上）。**关键填充**用径向渐变 `developGrad`，圆心设在 `cy=78%`（足印下缘偏下）——所以渐变天然"下暗（`#3A2A14`）→ 上亮（`#F4E3C2`）"，这就是显影梯度。前掌四个脚趾垫由上到下、由亮到暗依次排（`#F4E3C2`→`#E9C982`→`#D9A85B`→`#B98944`），上半部先显影、清晰实边。
3. **未显影的溶解边**：足印下缘（脚跟处）用 7 个 `developGrad` 填充、`opacity 0.85` 的散点替代实边——下半部"还没成形"，正在显影中途。

**比例**：足印高约占窗内径 85%，居中略偏上，给下缘溶解散点留呼吸位。窗框留白占四周约 12%。

**暗底上"显影/浮现"如何表达**：靠**单向径向渐变方向**（下暗上亮）+ **边缘两态**（上实下溶）。一个图形同时是"已现"与"暗中"。

**暖金高光位置**：`#FFF4DD` 纯亮小圆点，r≈3，**只打在足印最先显影的前掌顶点**（约 `186,96`）——显影盘里最先变黑的第一粒银盐 = 被看见的第一束光。全图唯一高光锚点。

**App 图标极简版怎么缩**：圆窗换 `rx=48` 圆角方（图标更稳），足印简化为**单一块面**（去掉四趾分层，只留两片亮垫 + 一个高光点），颗粒底噪去除。保留：渐变方向、上亮下暗、单点高光。

**去色版怎么成立**：渐变全部抛弃，足印降级为 `var(--p)` 2.5px **纯轮廓线**，脚趾垫变两个空心小圆，窗框 + 虚线骑缝保留。变成一枚标准单墨印章——凭证感来自"窗+缝+印"的几何，不依赖任何明暗渐次。

## 小尺寸 / 去色可辨性自评

- **轮廓辨识（★★★★★）**：圆窗 + 足印剪影是强轮廓，16px 图标仍读得出"窗里有一只脚印"，不会糊成色块。
- **去色可辨（★★★★★）**：纯轮廓印章版本身就是设计的一部分（已给出），单墨/压凹/烫金均成立，不靠渐变。
- **极小尺寸渐变（★★★☆☆）**：< 24px 时径向渐变的"下暗上亮"会被压扁、颗粒消失——**这是唯一弱点**。对冲方案明确：≤24px 一律切到"App 极简版"（单块面 + 一点高光），≤16px 或单色印刷切到"去色轮廓印章版"。
- **高光存活性**：暖金高光是缩小时最后消失的元素，也是放大时第一个被注意的灵魂点，分级降级路径干净。

整体小尺寸策略：**全彩显影窗（大）→ 单块面 App 版（中小）→ 纯轮廓印章（极小/单色）**，三级降级各自独立成立，没有"缩到一半两不像"的尴尬区间。

## 一、5 原则评分对比表(每条 1–5,满分 25)

评分锚点严格对齐已签收的 5 条裁判原则。打分看的是**该方向"作为静态标志成立时"对原则的契合度**,不看口头叙事的漂亮程度——叙事人人都写满分,但形里能不能立住才算数。

| 方向 | ① 凭证感 | ② 克制权威 | ③ 显影非点燃 | ④ 你的印非奖 | ⑤ 可被核验 | **总分** | 一句话点评 |
|---|:--:|:--:|:--:|:--:|:--:|:--:|---|
| **显影印鉴 Seal** | 5 | 4 | 5 | 5 | 5 | **24** | 疆域母语级,"印鉴"是凭证最纯原型,印心留给跑者落原则四最干净——主标第一候选。 |
| **银盐颗粒字标 Grain** | 4 | 4 | 5 | 5 | 4 | **22** | 概念最锐:字不是画的是冲出来的;但纯字标符号性弱、小尺寸硬伤,定位是"署名/水印"而非图标。 |
| **等高线段位 Contour** | 4 | 5 | 5 | 5 | 5 | **24** | "段位=海拔=显影层数"三义同形,差异化最高;唯一系统成本是小尺寸必须维护降层版。 |

| **散点聚合 Converge** | 4 | 4 | 5 | 4 | 4 | **21** | 最"长在疆域主轴上"——显影即成形方式;但抽象无具象符号、容错低,且与 Seal 的散点母题部分重叠。 |
| **暗房成像 Darkroom** | 4 | 3 | 4 | 3 | 3 | **17** | 圆窗+足印剪影轮廓强、小尺寸稳;但"足印"具象化偏运动 App 直觉,圆窗装饰元素多,克制与"非奖"两项偏软。 |

> 评分说明的三处关键扣分:
> - **Darkroom ④=3**:足印是"跑步行为"的直白符号,容易把主角从"跑者的身份印"滑回"跑步这个动作",离"被授予的凭证"最远;圆窗双描边+虚线缝+颗粒底噪元素偏多,克制(②=3)受损。
> - **Converge ④=4**:散点=跑者轨迹的解释成本高,"主角是跑者"需要叙事兜底,不如印鉴/海拔/邮戳一眼自证。
> - **Postmark ③=4**:邮戳天生是"已完成的盖章",显影时态要靠半显戳圈额外撑,中小尺寸退化为静态戳后"显影"信号最先丢。

## 二、推荐渲染清单(进比稿板的方向)

**推荐做成比稿板:Seal、Contour、Postmark、Grain(4 个主推) + Converge(候补第 5,作差异化对照)。**

### 入选

**1. 显影印鉴 Seal —— 必做,主标种子选手**
24 分并列最高,且是 5 个原则里没有任何一项 ≤4 的唯一方向。印鉴是"凭证"最不可辩驳的原型,印心可换跑者缩写/段位/城市年份天然长成子系统,去色与压凹是它的血统主场。它是这块板的"中锋",其它方向都要跟它比。

**2. 等高线段位 Contour —— 必做,差异化王牌**
同为 24 分,但赢在**独占性**:没有任何跑者身份品牌用"显影地形/海拔段位"。它把战略里"段位=海拔"的本土制度红利直接焊进形里,且天生是等级变体系统(亮到第几层=段位),接住"会成长的 logo"叙事。与 Seal 形成"印 vs 山"的两极,板上必须并置。

**3. 邮戳钢印 Postmark —— 做,凭证感+工艺落地标杆**
23 分,①⑤双满分,实体周边(烫金压凹)几乎零损耗落地,App 小尺寸硬骨架版("骑缝压断的暖金圆戳")是全场最稳的小图标解之一。骑缝断口是去色后仍能识别的独占结构特征。作为"凭证/签发"语义的代表必须上板。

**4. 银盐颗粒字标 Grain —— 做,但定位为"署名/水印"专用**
22 分,概念锐度最高(显影是构造而非滤镜),且它是唯一的**字标方向**——一块比稿板需要至少一个"名字本身被看见"的字标候选来覆盖主页头/署名场景。但明确它不竞争 App 图标主标,是体系的"署名声部"。

**5. 散点聚合 Converge —— 候补上板,作"纯显影动作"对照组**
21 分,留它**不是因为它能赢主标**,而是它把"散落→聚合→被看见"做成了最纯粹的一个动作定格,是动效起手式的最佳母本。上板作为"概念最干净的一极"供创始人对照,帮助确认 Seal/Converge 谁的散点处理更值得保留。

### 砍掉 / 降级

**暗房成像 Darkroom —— 不上主比稿板(降为质感参考)**
17 分,垫底,**砍掉理由两条**:
1. **足印具象化踩了"运动 App 直觉"的边**——5 原则里原则四明确"主角是跑者的身份印,不是跑步这个动作";足印剪影把叙事拉回"跑步行为",且足印是跑步 App 的烂大街母题,差异化为负。
2. **元素冗余伤克制**——圆窗外圈金框+内圈虚线缝+颗粒底噪+足印分层+高光点,叠了 5 类元素,违背原则二"删到不能再删"。
它唯一可取的"下暗上亮单向径向显影梯度"已被 Seal/Contour/Converge 更克制地实现,无独占价值。**保留其"显影窗"质感做 moodboard 参考即可,不占比稿位。**

> 另:**Converge 与 Seal 的散点母题同质**已被识别——若板上空间紧张,二选一时保 Seal(凭证感更强、可核验更硬),Converge 退为动效 spec。当前按 5 板推荐,是给创始人保留对照权。

## 三、推荐方向的"渲染要点"(SVG 还原时必须抓住的视觉特征,确保不画歪)

### Seal 显影印鉴
1. **圆方相济**:外圆=显影成像圈,内嵌圆角方=钢印印面;**外圆绝不画成连续实线**,而是 40–60 颗银盐颗粒"右上密大亮、左下疏小暗"聚拢成形——这是"散点成印"的命门,画成实线圈就废了。
2. **压凹靠双棱不靠填充**:方印心左上 `#FBF6E9` 高光棱 + 右下 `#0E1710` 暗影棱,中间面比底略亮——钢印立体感全靠这对明暗棱,去色后也得靠它独立成立。
3. **光只在两处**:印心左上一道高光棱 + 中心记号右上一粒米白点,高光总占比 <8%;**严禁任何外圈发光 glow**(那是霓虹,踩原则三)。

### Contour 等高线段位
1. **不闭合、不等距、偏心峰**:6 条是**地形剖面线**横跨左右缘、中部隆成峰,峰顶 x 统一对到 ≈132(偏右上),**绝不画成同心圆/等距环**——一闭合就滑回"进度环",直接出局。
2. **由暗到亮逐层显影**:L1 欠曝褐断续虚线(dasharray)→ L6 暖象牙实线渐变;**越低越断越暗、越高越连越亮**,这道明度梯度=显影,是灵魂,不能让 6 层同色同亮。
3. **顶点对焦命中点**:山峰 `(132,72)` 一粒 `#FBF4E2` 纯白实心点 + 向内柔光晕(不是向外辐射),可挂极短对焦角标——这是"被看见"的句号。

### Postmark 邮戳钢印
1. **半显戳圈**:外环沿圆周由 7 点钟近暗 → 12 点暖金 → 4–5 点钟 `#E8C07A` 最亮 → 隐回暗,**一圈即一次显影**,但不是进度条(它是光爬过金属边的痕迹,不带刻度/百分比)。
2. **垂直骑缝断口**:一条极细米白虚线把戳切左右两半,**左半实成/右半颗粒化未聚拢**,戳圈与骑缝相交处上下各留 ≈4° 小缺口——这是去色后唯一不能丢的识别特征。
3. **戳芯=上扬开口弧(非闭环)**:中央 3 条开口朝上的等高线弧(半径约 10/7/4),延续 Contour 母题且去进度条化;全图仅 2 处高光(戳圈右下 + 顶弧顶点)。

### Grain 银盐颗粒字标
1. **笔画即颗粒密度,不是描边**:用「跑印」实心轮廓作 mask,内部铺**规则点阵**(非随机噪点!随机噪点=glitch 做旧,出局),核心密大亮、边缘疏小暗,字边做 6–10px"显影羽化"不硬切。
2. **左暗右亮的显影锋面**:一条隐形左下→右上对角线,所有颗粒亮度/密度沿其法线插值,字像"正从左下被冲到右上";英文 RUNPRINT 同律。
3. **一粒对焦命中点**:全图唯一 `#FBF4E2` 纯定影点(落「印」字口部收笔或 R 接缝),最亮最实,给暗场一个"被看见"出口。

### Converge 散点聚合(候补)
1. **三环向心+从暗到亮的明度梯度**:外环 12 点最暗最疏(opacity 0.18–0.28)→ 中环 8 点 → 内环 6 点转暖金 → 中心实印;**点必须错开成梅花交错、不径向对齐**,严格限点(≤24)、限明度档(3 档),否则滑向"星空粒子特效"。
2. **中心实体印=主角**:钝角六边形空心钢印轮廓(用六边形不用圆,避免读成进度环)+ 印心一粒最亮金点。
3. **单一光源左上 315°**:仅中心印左上弧段提亮成高光,内环朝左上 2 点呼应,全图一处光源逻辑。

## 四、可能的"组合 / 混血"

显影是共同母语,母题可互换、显影手法可移植,以下是值得在比稿板上**实做的杂交样本**:

1. **Seal 母题 × Grain 显影手法 ⭐最强混血**
   印鉴的钢印外壳 + 印面字用"银盐颗粒密度"显影成形(而非实心填充)。= "一枚正在被颗粒冲洗出来的印"。同时拿到 Seal 的凭证感(24)和 Grain 的概念锐度,补上 Grain 纯字标符号性弱的短板。**建议作为主标第一精修对象。**

2. **Contour 母题 × Postmark 形制**
   把"等高线山形"收进一枚圆戳里作戳芯(Postmark 的戳芯方案 A 本就是 3 弧等高线,直接升级为偏心山峰剖面)。= "一枚盖着你海拔段位的签发戳"。凭证感(戳)+ 差异化(海拔)+ 可成长(段位)三收,且天然是邮戳子系统(印心换城市年份)。

3. **Converge 显影动作 × 任意主标的"入场动效"**
   Converge 的"散点由外向内、由暗到亮逐帧聚成印"是最佳通用入场动画。无论主标定 Seal 还是 Contour,**动效都用 Converge 的聚合逻辑**——这样 Converge 即使不当主标,也作为"动效母本"进入体系,价值不浪费。

4. **Seal × Contour 的"印心可换"系统**
   同一 Seal 外壳,印心槽位**插 Contour 山形**作段位徽。= 印鉴负责"凭证/签发",山形负责"段位/海拔",两个 24 分方向合体成一套可成长身份系统,而非二选一。

## 五、作为标志系统的建议(主标 / App 图标简化版 / 署名水印版)

> 原则:一套系统,三种降级各自独立成立,**没有"缩到一半两不像"的尴尬区间**;品牌始终退居签发位,主角是跑者。

| 用途 | 推荐方向 | 理由 |
|---|---|---|
| **主标(公开主页头 / 海报主体 / 实体周边)** | **Seal 显影印鉴**(精修时融入混血 1:印面字颗粒化) | 凭证感+疆域契合双满分,印心可个性化天然长成子系统,大尺寸颗粒环+压凹钢印质感最稀缺;是唯一无短板项的主标。 |
| **App 图标简化版(≤48px,去色仍可辨)** | **Postmark 硬骨架版**(暗底 + 实心暖金戳圈 + 骑缝压断双缺口 + 单上扬弧) / 备选 **Seal 纯形版**(暗底+压凹方印+一道暖金高光弧) | 邮戳是方圆原型,本就为小图标而生;"骑缝压断的暖金圆戳"16px 仍一眼可辨且去色不垮。Seal 纯形版作主标家族内的一致性备选。 |
| **署名 / 水印版(海报右下角 / 公开分享资产)** | **Grain 银盐颗粒字标**(暗底浮金,半透叠加) | 字标天生承载"名字本身被看见",暗底浮金在信息流里唯一发光,半透明颗粒字作署名/水印语义最自洽;它的小尺寸短板在水印场景(通常中大尺寸)不构成问题。 |
| **段位 / 认证子系统(完赛戳 / 等级徽)** | **Contour**(亮到第几层=段位)嵌入 Seal 印心(混血 4) | 靠"显影层数"表达段位,无需彩虹分级或加桂冠,严格渐进披露不羞辱新人;落原则四+原则五。 |
| **动效签名(启动 / 完赛弹窗 / 显影落定)** | **Converge 聚合逻辑**(散点由外向内、由暗到亮显影成印) | 不占静态标志位,作为全系统统一的"显影成像"入场动作,把疆域主轴"散落→显影→被看见"在时间轴上展开。 |

**系统一句话**:**主标用印(Seal)、小图标用戳(Postmark)、署名用字(Grain)、段位用山(Contour)、动效用聚(Converge)**——五个方向不是五选一,而是按场景各司一职、共享"暗底浮金/由暗到亮显影/品牌退居签发位"的同一套显影血统。砍掉 Darkroom(足印偏运动直觉、元素冗余),其质感降为 moodboard 参考。
