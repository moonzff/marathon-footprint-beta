## 0. 为什么要有这份文件(纠错前提)

本轮要纠正一个**方法论错误**,而非否定已有成果:

- `01-foundation.md` 把"系统概念 / 品牌 / 视觉 / 人群"压在**同一次 P1 拍板**里一起定死(第 5 行"P1 已定"),并把**视觉(档案绿 `#17412D` / 同心环纹 / 现代宋)标为"定稿"**(第三章)。
- `00-design-workflow.md` 第 63 行把这些视觉结论作为**既定输入**写进了《设计 Brief》的"品牌锚点"字段。
- `04-logo-pitch.md` 的 6 个 logo 方向,全部从"同心环纹"这个**预设结论**收敛 —— 这是**循环论证**:用"已定的视觉"去推导"该选哪个 logo"。

**业界八大框架无一例外**(Alina Wheeler 五阶段 / Neumeier / Aaker / Keller CBBE / Brand Key / 黄金圈 / 12 原型 / Double Diamond),都把"视觉识别"排在"研究 → 战略 → 语言"之后。

> **一句话铁律:视觉是战略的产物,不是创作的起点。Logo、色彩、图形母题都不能预先锁定,它们必须是从已讲透的战略、定位、人群、概念里推导出来的结论,且必须可被战略证伪、可被替换。**

好消息:**已有调研质量很高,约 80% 的战略原料已就位**。真正缺的不是重做调研,而是**把丰富素材灌进"能当裁判"的结构化模板**,补上几个被跳过的中间产物,并把视觉从"前提"降级回"待推导的候选"。

## 1. 总纲:六阶段顺序 + 双钻外壳

阶段主干借 **Alina Wheeler 五阶段**(行业标准教科书《Designing Brand Identity》),拆出"语言"独立成阶,得到六阶段;节奏外壳借 **Double Diamond**(英国设计委员会),管发散/收敛与**允许回退**。

```
        研究 ──► 战略 ──► 语言 ──► 视觉 ──► 系统 ──► 指南
      Research  Strategy  Verbal   Visual   System  Guidelines
     │ Discover │ Define │ Develop(verbal) │ Develop(visual) │ Deliver │ Deliver │
       └──────────── 任一阶段被证伪,可回退上游(双钻的迭代环)────────────┘

   ════════ 战略签收闸门 ════════              ════════ 视觉方向闸门 ════════
   (战略定稿前,视觉一律不许启动)            (选"一条视觉路",不是选 logo)
```

**两条不可破的铁律(贯穿全流程):**

1. **战略先于一切表达**(strategy-before-expression):定位 / 价值主张 / 受众 / 差异化故事先定稿,才轮到任何表达层。
2. **语言先于视觉**(verbal-before-visual):命名 / 声音 / tone / messaging 架构先立,视觉从语言与战略**推导**而来,不可反向。

**两道硬闸门(gate):**

- **战略签收闸门**:阶段 1 的《品牌战略书》创始人签字确认("这就是我们是谁,与任何颜色/形状无关")之后,才允许进入阶段 3 视觉。
- **视觉方向闸门**:阶段 3 中段,创始人选定 **1 条 Visual Territory(视觉疆域)**,而非选一个 logo;选定后才进入精细识别设计。

## 2. 阶段表(目的 / 输入 / 关键活动 / 交付物 / 框架)

| 阶段 | 目的 | 输入 | 关键活动 | 交付物 | 用哪个框架 |
|---|---|---|---|---|---|

| **2 语言** Develop-verbal | 用文字独立讲清品牌,**还没碰颜色和 logo** | 战略书 | 命名证据化(打分卡+商标查名)、Messaging House、Voice&Tone、Tagline 体系、品牌叙事 | 《语言识别手册》 | Messaging House · NN/g Voice/Tone 四维 · StoryBrand SB7 · 命名类型学 · VPC |
| **3 视觉** Develop-visual | 从战略+语言**推导**视觉,多方向比稿后定稿 | 战略书 + 语言手册 | 设计原则提炼、关键词→视觉翻译矩阵、Moodboard、2–3 条 Visual Territory、logo 发散→收敛→精修 | 《设计原则》+《视觉策略(Territories)》+ 定稿视觉识别 | Design Principles · Attribute-to-Visual 矩阵 · Visual Territory · logo 四步流程 |
| **4 系统** Deliver | 把视觉编码成可被产品消费、可扩展的系统 | 定稿视觉 | Foundations → Tokens(三层)→ Components → Patterns | 《设计系统》(文档站 + Figma 库 + token 包) | Atomic Design · W3C Design Tokens · Material/Polaris/Carbon 结构 |
| **5 指南** Deliver | 让第三方照着用而不跑偏 | 战略+语言+视觉+系统 | 编纂规范、do/don't、应用场景、治理 | 《跑印品牌手册》+ 治理规范 | Brand Guidelines TOC · SemVer 治理 |

## 4. 当下起点:从阶段 1 的《品牌战略书》开始

**现在应做的第一份文字交付物 = 阶段 1《品牌战略书》(`1-brand-strategy.md`)。**

理由:研究(阶段 0)已基本充分;战略是所有下游(语言、视觉、系统)的"宪法第一条";且它是把"档案绿/同心环纹"合法降级的前提 —— 只有先把战略独立讲透,视觉才能成为它的可证伪产物。具体动作:把 `01-foundation` §一·二·四抽出,**清除一切视觉内容**,灌进下列提纲。

### 《品牌战略书》提纲(`1-brand-strategy.md`)

```
0  元信息:版本 / 状态 / 上游依赖(blueprint, athlete-report)/ 本文档不含任何颜色与形状

A  品牌内核 Brand Core
   A1 Purpose / Why(黄金圈)——为何存在
        候选:让每个认真的跑者,被完整、可信地看见
   A2 Vision 愿景(未来终局,北极星)
   A3 Mission 使命(现在做什么去那里)
   A4 Values 价值观(已有 5 条,复核保留)

B  品类定位 Category Positioning(最高杠杆,先于品牌定位)
   B1 心智阶梯判断:拒绝"跑步记录 App"阶梯,自建"跑者完赛身份层"新阶梯当第一
   B2 品类名(需可传播,如"完赛身份层 / 生涯聚合层")
   B3 Category POV:世界变了 → 旧方案解决不了的新问题 → 需要新品类 → 我们定义它
   B4 感知地图(2×2):X 单平台记录↔跨平台聚合,Y 工具导向↔身份导向,标出 white-space

C  品牌定位 Brand Positioning
   C1 结构化定位声明(Dunford 5 要素 → Moore 模板,替代散文):
        For X who Y, Runprint is Z that W, unlike V, because RTB
        ★ Z 槽位必须填"中立的身份引擎",不许填"海报工具"(战略红线执法点)
   C2 Onliness 陈述(Zag,锐度终检 + 品牌宣言母版):
        唯一的 ___,做到 ___,为 ___,在(时代)___,因为(信念)___
        测试:把 Runprint 换成竞品,这句话必须不成立
   C3 价值主张:功能利益 + 情感利益 + 自我表达利益(★ 身份产品命门,需补强)
   C4 Reason to Believe(RTB,结构化):中立 + 田协背书 + OCR 覆盖面 + 去重验证
   C5 差异化矩阵 POP / POD / POF
        POP(及格即可) | POD(80% 资源压这里) | POF(主动不做,强化锐度)
   C6 Aaker 四视角:品牌作为 产品 / 组织 / 人 / 符号(Symbol 留待阶段 3 推导)

D  品牌人格 Brand Persona(为语言与视觉提供个性输入)
   D1 原型复核:Sage(智者)+ Creator(创造者)—— 正式验证由战略推出,非预设
   D2 个性 5 词:可信 · 懂行 · 克制 · 讲究 · 有底气
   D3 Brand Essence / Big Idea 候选:每一场,都算数(待确认)

E  受众 Audience(对位进各阶段的人群依据)
   E1 Beachhead:资深跑者(主)+ 跑团 KOC(分发器)
   E2 Persona 2–3 张(★ 补 KOC 卡,现仅有资深跑者独白)
   E3 JTBD Job Story 清单(功能/情感/社会三层 + 对应功能号)

附:1 页定位平台(全书蒸馏版)——蒸馏不出来 = 战略本身没收敛
```

**完成标准(战略签收闸门):** 定位声明能用一句话过;Onliness 通过"换名失效"测试;全书不依赖任何视觉决定;创始人签字。**签字后,才允许启动阶段 3 视觉。**

见第 4 节完整提纲。三段骨架:`Brand Core(Purpose/Vision/Mission/Values)· Brand Positioning(品类+品牌定位/价值主张/RTB/POD/Aaker 四视角)· Brand Persona(原型/个性/essence)`,附 1 页定位平台。

### ④ 视觉 Territory(视觉疆域,每条一张)

> 至少产 2–3 条(如 A 档案绿·田野档案 / B 段位黑金 / C 显影暗房),给档案绿一个公平对手。

### ⑤ 品牌手册 TOC(阶段 5 交付骨架)
```

3 视觉识别(logo/色彩/字体/图形语言/影像[含肖像权红线]/版式/动效)

```

### ⑥ 设计系统 TOC(阶段 4 交付骨架)

## 6. 精简版路径(独立开发者/初创最务实,别过度重型)

成熟框架是"全家桶",初创不必全套上。**一条流程主干 + 三件内容工具**即可:

| 角色 | 选用 | 为什么不用全套 |
|---|---|---|
| 流程主干 | **Wheeler 六阶段**(本文总纲) | 唯一端到端、强制顺序 |
| 差异化引擎 | **Zag Onliness** 一句话 | 初创命门是"卡空位",最锐利 |
| 战略落地单页 | **Brand Key 9 格** | Aaker 的快消化单页版,性价比远高于 Aaker 全套 |
| 个性层 | **12 原型**(已选 Sage+Creator) | 把个性变可操作 |
| 辅助 | 黄金圈(提炼 Why)+ CBBE(上线后量品牌健康) | 起手与度量,不做主框架 |

**精简版的"够用就好"边界:**

- **阶段 0–1 合并交付一份**:研究综述直接收口进战略书的市场/竞争语境段,不单独成大部头。
- **阶段 1 最小集**:Onliness 句 + 一页 Brand Key + 结构化定位声明 + POD 表 + 原型确认。**这一页就是签收闸门的全部**,不必写 40 页。
- **阶段 2 最小集**:Messaging House 一页 + Voice chart 一页(5 词展开 Do/Don't)。命名已定,只补一张打分卡 + 一次商标 knockout 留证。
- **阶段 3 不可省的只有一件:《设计原则 3–5 条》** —— 这是战略→视觉唯一不可跳的桥。Territory 出 2 条即可(档案绿 + 一个对手),不必 3 条。
- **阶段 4–5 按需延后**:产品还在原型期,先用低保真(SVG/HTML/md)推进,token 化与品牌手册等视觉定稿、产品成形后再做。**别在没有组件消费方时提前建重型设计系统。**

> **精简版一句话:把 80% 已有素材灌进 Brand Key + Messaging House + Voice Chart + 设计原则这四张纸,跑通"战略→语言→设计原则"三关,视觉自然从中长出来。其余重型产物(Aaker 全套、完整 design system、品牌手册)等产品长大再补。**
