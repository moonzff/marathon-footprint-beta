01 — Logo标志 · 同心环纹

一个符号,四义同形:指纹(唯一·可信)· 跑道折返圈(运动)· 等高线(足迹/地理)· 完赛圈数(生涯)。环心缺口=起跑/完赛拱门,外圈断开收口成带箭头的折返跑道。

  • 环心缺口 = 起跑/完赛拱门(橙色高亮)——一切从这里出发、回到这里
  • 内圈实环 = 指纹核心,身份的唯一性与可信
  • 外圈断口 + 箭头 = 折返跑道与运动方向
  • 环越多 = 跑过的圈越多 / 完赛越多 → 画像越厚(会成长的标志)

这一稿要传达的:

  • 主角永远是成绩与赛事(等宽大字),不是滤镜
  • 完赛金只用在荣誉峰值(PB/等级/邮戳),克制=高级

  • 整体像一张可裱起来的完赛证书,不是运营图
