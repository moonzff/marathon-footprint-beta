# Marathon Footprint Poster Lab

独立海报方向实验区，不修改现有项目。

## 目标

只探索完赛海报，不接真实保存逻辑、不改线上版本。

## 三个方向

1. `official` - 赛事官方感：深色、成绩主导，不依赖照片。
2. `runner` - 跑者主角感：只有真实抠图或清晰单人照片时启用，其他元素让位。
3. `certificate` - 成绩证书感：信息最清楚，照片只是可选附加素材，不抢正文。

## 决策标准

- 先看整体是否像一张值得分享的海报。
- 再看照片是否抢主角、是否截得尴尬。
- 最后看成绩、赛事名、日期、号码、城市是否完整可读。

## 打开

直接打开 `index.html`，或启动本地静态服务预览。
