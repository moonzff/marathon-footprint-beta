# 跑马纪念册 · 项目蓝图 v1（2026-06-19）

> 新接手者视角的重定位与重规划。基于一轮全网调研（中国路跑市场 / 国内竞品 / 全球对标 / 变现模式），四路结论高度收敛。
> 战略前提（已与产品负责人确认）：**国内先验证→再出海** · **认真做可盈利产品** · **负责人是资深跑者**（天然种子用户+内容源+分发渠道）。

---

## 0. 一句话重定位

> **不要把自己定义成"又一个海报/纪念册工具",而是做"跑者完赛生涯的中立聚合层 + 身份引擎":**
> 用 **OCR + 用户授权导入** 收纳一个人跨平台、跨赛事(含线下/海外/越野/小众赛)的**全部完赛资产**,把它变成一本会成长、可炫耀、可分享的**数字跑马生涯**;并在每一次完赛的**情绪峰值**用一次性数字/实物 keepsake 变现。

纪念册、海报、城市地图都只是这个定位的**表现层**;真正的护城河在**聚合 + 身份 + 变现时机**。

## 1. 调研核心结论（收敛事实）

**市场（来源：中国田协《中国路跑蓝皮书》、国家体育总局、国务院政策）**
- 2024 全国路跑赛事 **749 场 / 704.86 万人次**;认证赛事完赛 **220.54 万人次**;累计已有 250 万+ 全马/半马完赛人群。
- 跑者**年均跑步相关消费 ¥14,141**,2024 路跑消费总规模 **168 亿+(同比 +26%)**,持续两位数增长。
- 人群:**35–49 岁、本科以上占 48.6%、企业职员/管理者过半**——高学历、高可支配收入的城市中年。
- 供给侧 2025 主动回落(749→594 场)但人均消费、经济效益、中签竞争度**全部上升**——市场从"拼数量"转向"存量精品",**利好面向存量跑者的纪念产品**。
- 需求显著过热:头部赛事中签率 **6–11%**,黄牛溢价最高 **24 倍**——证明跑者对"完赛荣誉感/身份感"高度敏感且**有真实付费意愿**。
- **大众选手等级**(精英/一级/二级 × 8 年龄组 × 性别)是中国田协官方背书的"段位"体系——**西方 Strava/Athlinks 无法复制的本土制度红利**。(获评总人数官方未披露;可用"2024 破三超 1.8 万人"作精英级代理参照。)

**竞争格局(空白真实存在)**
- 跑者完赛资产**高度分散**:成绩在田协/数字心动、照片在爱云动、证书各赛事各自下发、奖牌只在线下。
- **没有任何一家**把"真实完赛成绩(含线下/海外/越野)+ 证书 + 奖牌 + 城市足迹 + 精美海报 + 可炫耀公开主页"打包成 C 端数字纪念册。
- 两个需要绕开的"近邻":官方 **《中国马拉松护照》**(占住"护照"之名+官方成绩源,但政务感、只覆盖田协共办赛、无海报/地图/社交);**爱燃烧**(最接近成绩+证书+照片聚合,但工具型门户、增长乏力)。
- 咕咚/悦跑圈/Keep 的奖牌墙**全部绑定自家线上赛**,不聚合真实线下生涯;且做"中立聚合"与其"卖自家线上赛奖牌"的核心商业模式**利益冲突**——**大厂没动机认真做**。
- **小红书是分发/社交层,不是聚合层**:它放大了"晒"的需求,但一切靠用户手动截图+套模板拼图,没解决"晒得累、没生涯沉淀"的痛点。
- **关键壁垒 = 国内成绩无统一对外 API**。本产品现有的 **成绩单 OCR + 用户授权导入** 正是绕过这一壁垒的钥匙,且覆盖面比官方/大厂更广(海外/越野/小赛都能进)。

**全球对标(出海期可借的"形")**
- "聚合我所有成绩成一个漂亮主页"这件事**全球也没人干净地拥有**:Athlinks 有聚合但工具化、归 Life Time/计时公司、出美国即弱;Strava 拥有社交身份但是 activity-centric,**没有完赛证书/奖牌/官方照片的概念**;AWMM "Six Star" 只覆盖六大满贯。
- 可迁移机制:**收集任务式的有限荣誉集**(Six Star)、**自动填充的成绩看板**、**公开 Hall of Fame/可搜索身份**、**自我对比徽章/连胜/彩带**(Nike Run Club)、**实物-数字桥**(The Conqueror 邮寄奖牌、NOTCH 纪念手环)。
- 战略巧合:全球两大赛事照片品牌 MarathonFoto + Sportograf 现都归 **万达体育(中资)**——出海期的潜在合作/数据角度,而非纯竞争。

**变现(证据强烈指向"按次,不是订阅")**
- 订阅渗透连头部都只有 **Strava ~2–4% / Keep ~10.7%**,健身 App 月流失 ~9.2%——对"一年用 1–2 次"的低频纪念产品是**错配**。
- 反例验证:Keep **卖线上赛奖牌**(¥39/69/139)做到单场数十万付费、GMV 超 9000 万;跑者真实地"4 个月买 70 块奖牌 ≈ ¥3000"。**跑者付费买的是可炫耀的 artifact + 完赛高光时刻,不是工具或运动本身。**
- 实物 SKU 标杆:路线图海报数字版 €7.95 / 打印 from $18–25(My Adventure Maps、Mark Your Moment);照片书学 **Chatbooks**——把"每场赛事自动成册 + 年度自动汇编"变成订阅式复购(~$180–220/年/客户)。
- B2B2C 已有先例:Athlinks/Bhaago/RunSignup 都送品牌化数字完赛证书;**adidas×Qurable NFT 奖牌**解锁 AdiClub 会员漏斗——**赞助商买单的数字完赛纪念**是合理预算项(大赛单场赞助 ¥1000 万级)。
- **红线**:2025 爱云动 55 万张未授权照片引爆肖像权争议——**任何照片功能必须走用户自传或赛事方授权**,并把"合规授权"做成卖点。

## 2. 发散：4 个战略下注角度，与收敛推荐

把项目想象成不同的"主语",会得到四种可能的公司：

| 角度 | 一句话 | 类比 | 护城河 | 风险 |
|---|---|---|---|---|
| **A. 身份/社交** | 做"跑者版 Letterboxd/Strava 完赛身份层" | Letterboxd · Six Star | 网络效应 + 等级身份 | 需规模才有社交价值,冷启动重 |
| **B. 纪念品商务** | 做"跑者版 Shutterfly/Chatbooks",卖数字+实物 keepsake | Chatbooks · The Conqueror | 复购节律 + 供应链 | 低频、物流、获客成本 |
| **C. B2B2C 白标** | 给赛事方/品牌做"官方数字完赛纪念+曝光漏斗" | Athlinks 证书 · adidas×AdiClub | 赞助预算 + 官方渠道 | 销售周期长、依赖 B 端 |
| **D. 等级游戏化** | 把大众等级做成"段位进阶 RPG" | 王者荣耀段位 · Smashrun 徽章 | 本土制度红利 | 单点易被官方/大厂抄 |

**收敛推荐:不是四选一,而是有顺序的组合 —— 以 A(身份聚合)为内核、B(按次 keepsake)为现金引擎、D(等级)为留存钩子,C(B2B2C)在增长期对冲低频。**

理由:
- A 是**唯一真正的空白且能复利**(聚合越多越值钱、生涯越长越离不开),但单靠 A 不赚钱;
- B 是**已被 Keep 验证有人付钱**的现金流,且本产品已掌握生成 keepsake 所需的全部数据;
- D 是**最便宜的差异化和留存**(把官方制度红利变成情绪钩子),且竞品抄不动"聚合+等级"的组合;
- C 是**唯一能对冲"一年只跑 1–2 次"低频/季节性**的稳定收入,但需要 A/B 先跑出用户量才有谈判筹码。

## 3. 价值主张与三层护城河

**对跑者的承诺**:"把你跑过的每一场,变成一本会成长、值得晒、随时能分享的跑马生涯。"

1. **聚合护城河(数据)**:平台中立 + OCR/授权导入,覆盖**官方做不到的全赛事范围**(线下/海外/越野/小赛)。用户贡献的赛事元数据(已有别名匹配雏形)众包成库,**越用越全、越难被复制**。
2. **身份护城河(情感)**:大众等级实时计算 + "距下一级差 X 分钟" + 自定义收集任务(本土版 Six Star,如"中国六大满贯""一城一证""百马")+ 城市足迹地图 + 可分享公开主页。**这是 Strava/Athlinks 缺失、官方做不出体验的层。**
3. **时机护城河(变现)**:在**完赛情绪峰值**这一刻提供一次性数字/实物 keepsake,转化率远高于日常订阅。竞品的奖牌墙绑死自家线上赛,**无法在"真实完赛那一刻"出现在用户面前**。

## 4. 商业模式（分阶段变现）

**核心判断:主引擎是"完赛峰值的一次性交易",订阅只做辅助,广告/分佣只做点缀。**

**验证期(0→1,先证明有人愿意付钱)**
- 💰 **完赛数字纪念册/海报** ¥9.9–39(核心):免费基础版可晒朋友圈(拉新),付费解锁高级模板/动效/数据丰富版(学 Strava:分享免费、精修付费)。
- 💰 **路线图/成绩单实物打印** ¥59–129:最低摩擦的首个实物 SKU,一件代发零库存(对标 Mark Your Moment $18–25)。
- ❌ 验证期不碰订阅、不碰自建奖牌库存(MOQ 风险)、不靠广告。

**增长期(1→N,做大 LTV、对冲低频/季节性)**
- 💰 **年度跑步纪念册**(学 Chatbooks):每场自动成册 + 年终自动汇编(实体 ¥99–199),把"一年 1–2 次"变成"每次完赛 + 年终"的复购节律。
- 💰 **预售制定制奖牌/奖牌墙/相框**(对冲 MOQ)。
- 💰 **B2B2C:赞助商/赛事方买单**(最大开放车道)——"品牌冠名的官方数字完赛纪念 + 会员漏斗"作为特步/安踏/On 的 marketing 预算项;给赛事方提供白标数字证书/纪念册做获客与曝光。**B 端预算稳定、季节性弱,直接对冲 C 端低频。**
- 💰 **轻订阅(辅助)** ¥88–128/年:全年无限模板+优先找照片+专属勋章,只面向被验证的高频跑者。
- 💰 **品牌赞助挑战赛**(对标 Strava×Lululemon 40|80)作为社区变现+拉新,而非 banner 广告。

## 5. 产品路线图（对齐现有 8 屏 + 要补的能力）

现有原型(参赛护照 / 城市足迹地图 / 完赛档案 / 单场纪念册 / **成绩单 OCR** / 完赛海报 / 同场跑友 / 公开主页)与本蓝图**高度吻合**——OCR 是已验证正确的楔子,海报是病毒分享单元,护照+地图+主页是身份层。重点不是推倒重来,而是**补身份引擎、修变现时机、做实分发**。

**P0 验证期(秋季赛季前,~3 个月)**
- 打磨 **OCR 导入 → 结构化 → 入册** 的端到端体验(这是命脉,容错与手动校正已在做)。
- **大众等级引擎**:自动计算当前等级 + "距下一级差 X 分钟" + 等级勋章(本土红利、低成本高情感)。
- **完赛海报一键生成 + 公开主页分享链接**:打磨成"晒到小红书/朋友圈零摩擦"的病毒单元。
- **付费点 1**:数字纪念册/海报高级版(¥9.9–39)。验证"完赛即付费"转化率与客单价。
- 守住红线:照片只走**用户自传/赛事方授权**,把"合规授权"写进产品文案。

**P1 增长期**
- 自定义**收集任务**(中国六大满贯/一城一证/百马进度)——本土版 Six Star。
- **年度纪念册**自动汇编 + 实物打印(复购引擎)。
- **同场跑友社区**做厚(同场 PB 播报、赛道照片墙)——制造赛间/淡季触点。
- 接 **B2B2C**:1–2 个区域赛事方白标试点 + 1 个运动品牌赞助纪念册 PoC。

**P2 出海期(国内模型验证后)**
- 英文版,机制迁移 Six Star/Strava 身份玩法;对接 Strava 生态(导入)+ 探索与 MarathonFoto/Sportograf(万达体系)的照片授权合作。

## 6. 冷启动 GTM（用足"负责人是资深跑者"这张牌）

低频产品的获客是最大风险(LTV:CAC 对一年用 1–2 次的产品极难)。打法必须是**内容驱动+赛季驱动+圈层驱动**,而非投放。

1. **自带种子**:用负责人自己的完赛履历做"活体 Demo 主页",在自己的跑团/跑圈做第一批真实用户和口碑。
2. **小红书 KOC 内容引擎**:把"我跑过的 23 场,一张图看完"这类**生涯聚合主页/海报**做成天然的小红书爆款素材(平台已是晒完赛主阵地,且自带模板需求)。用真实跑者身份做内容比投放可信 10 倍。
3. **赛季驱动**:锁定**秋季赛季**(厦马/上马/北马/锡马)做发布与增长高峰;淡季靠"导入你的历史生涯"提供**离赛事也有价值的即时钩子**(Day 1 就能把过去十几场聚合成册)。
4. **赛事现场地推/扫码**:完赛拱门旁"扫码生成你的完赛纪念海报"——在情绪峰值精准触达。
5. **同场效应**:同一场比赛的跑友互相可见→自然裂变,定向运营少数热门赛事而非全国铺开。

## 7. 关键风险与对冲

| 风险 | 证据 | 对冲 |
|---|---|---|
| **低频**(人均一生 1.5–2 场马) | marathonhandbook | 以"全生涯聚合"提供离赛事也有的价值;年度册+等级进阶造赛间触点;B 端收入垫底 |
| **季节性**(春秋集中) | 2024/11 单周 30+ 场 45 万人 | 旺季集中收割完赛流量,淡季靠 B2B 合约与历史导入 |
| **留存**(无每日钩子) | 健身 App Day30 留存 3–12% | 不假装是日活 App;靠"生涯+等级+社区"做中频情感钩子,不做日活 KPI |
| **肖像权红线** | 爱云动 55 万张未授权照片争议 | 照片只走用户自传/赛事授权,合规做成卖点,绝不抓取 |
| **数据获取**(无统一 API) | 行业共识 | OCR+授权导入为主路径,这是壁垒不是阻碍;众包赛事库复利 |
| **大厂顺手碾压** | 咕咚/悦跑圈/Keep | 与其"卖自家线上赛"利益冲突→无动机;聚合+等级+审美组合非其 DNA |
| **"报名来的不是真实用户"** | 马拉马拉/咕咚教训 | 不靠赛事报名引流,靠"生涯纪念"留存;价值锚在赛后而非赛前 |

## 8. 北极星指标与 Go/No-Go 闸

- **北极星**:**月度"生涯主页被分享/被访问次数"**(同时代表身份价值与病毒传播),次级看**完赛→付费转化率**与**人均年内入册场次**。
- **验证期 Go/No-Go(建议一个赛季后评审)**:
  - ✅ 继续:完赛付费转化 ≥ X%(对标 Keep 线上赛付费规模)、生涯主页有机分享带来 ≥ Y% 新增、留存出现"赛后回访"信号。
  - ❌ 收手/转向:导入摩擦过高致 OCR 留存崩、付费意愿验证不及预期、获客只能靠投放。

## 9. 立即下一步（建议优先级）

1. **锁定 P0 范围**:OCR 导入体验 + 大众等级引擎 + 海报/主页分享 + 第一个付费点。
2. **把现有 beta 的等级计算补成"实时+距下一级"的引擎**(已有大众等级雏形,差进阶叙事)。
3. **做 1 张负责人自己的生涯主页**作为冷启动素材与小红书首发内容。
4. **定一个目标赛季和 3–5 个种子赛事**(优先负责人能现场触达的)。
5. **付费点最小验证**:数字纪念册高级版 ¥9.9–39 的支付闭环 + 转化埋点。
